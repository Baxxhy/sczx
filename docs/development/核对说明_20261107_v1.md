# 错题帮网页版核对说明

日期：2026-11-07　版本：v1

`sczx` 里已经是普通 Vue 网页和 Python 服务，数据仍存在 MySQL。原来的项目保留，网页版运行时不需要启动仓颉或旧 uni-app。

现在功能和使用流程已经跑通。还存在下面列出的显示差异，因此目前没有标记为“与原版完全一样”。

## 已经保留的功能

- 登录、注册、资料修改和学习偏好。
- 手动录题、选择题图、裁剪、识别、核对文字和保存原图。
- 答案分析、定位出错步骤、辅导订正、自检和学习记录。
- 题库练习、考试、复习安排，以及刷新和返回后恢复内容。
- 知识框架、学习统计、原有维护页面和访问权限。
- 试卷生成，PDF、答案 PDF 和 Excel 导出下载。
- 原有的语音合成和转写后台功能。原版网页没有麦克风录音入口，本次也没有额外新增。

## 真实模型验证过的例子

程序绘制的题图是 `2x+3=11`。实际模型识别出题目后，网页先让学生核对内容；输入错误过程 `2x=14、x=7`，再点击确认和分析，后台核验的正确答案是 `x=4`，网页标出第一步出错，并提示将这一步改为 `2x=8`。刷新后，仍能读取同一条诊断，原始图片也完整保存。

[查看实际网页诊断截图](../../.runtime/http-smoke/02160c84/live-model-diagnosis.png) · [查看检查记录](../../.runtime/http-smoke/02160c84/live-model-browser.json)

语音也实际跑过“文字生成音频，再上传转成文字”的过程，音频能保存和下载。这个例子中出现了“已知”被识别成“一支”的误差，转写结果可以编辑。

## 还没有完全一致的地方

**一处明显差异，需要确定处理方式：短题型列表。**

原版 H5 在手机宽度下，只有3个选项的题型列表会把选项放到可见范围外。新版目前能够正常选择。已提供两个方案，尚未收到选择：

1. 保留新版能够正常选择的列表。
2. 严格复现原版的显示问题。

[查看原版截图](../../.runtime/page-compare/full-page-host-final/pages-manual-manual-ui_picker-2-390-original.png) · [查看新版截图](../../.runtime/page-compare/full-page-host-final/pages-manual-manual-ui_picker-2-390-vue.png)

**另外7对截图只有极少量颜色数值差异。** 每对涉及8至57个像素，最大颜色通道差为1级，原始统计保留在上表的外观记录中，没有忽略或改成通过。

补充核对：对这些页面另做了12对“原版与原版”的截图比较，其中11对完全相同，复习搜索页也出现了24个像素、最大1级的颜色差异。这证明该页存在原版自身的渲染波动，但不能据此认定其余页面差异都属于波动。

## 怎么启动

先按 [README 的安装和启动步骤](使用说明_20261107_v1.md#安装和启动)，配置一个独立的 MySQL 数据库和环境文件。然后在 `sczx` 目录运行：

```bash
.venv/bin/python scripts/run_local.py
```

默认用浏览器打开 [错题帮网页版](http://127.0.0.1:5176)。停止时在启动终端按 Ctrl+C。
