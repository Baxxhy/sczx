# 前端视觉与交互设计

日期 2026-11-09　版本 v7

当前只建设桌面Web，使用Vue 3＋JavaScript、Nova中性色主题、项目内shadcn-vue组件、Reka UI、Lucide、motion-v、Pinia及VueDraggable。分栏复用Reka Splitter，不引入React或TypeScript业务工程。

页面以深色正文、明确主操作和实际内容层级组织，不通过重复说明填满空间。已发布只读字段保持可读对比度。课程工作台采用目录、内容编辑与学生预览；学习页采用内容、真实课时目录与学习助手。表单保留标签和焦点，发布、停用和删除说明后果。

当前桌面走查宽度为1440、1920、2560，覆盖键盘调整分栏、内容排序、125%内容缩放、长内容、图片失败恢复和无效详情。以下课程与材料图片来自第六、七步实际浏览器验收，自编内容与演示账号不代表真实教师评审。
