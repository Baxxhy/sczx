# 师承智学前端视觉与交互设计

日期 2026-11-07　版本 v3

## 1. 本轮设计与预览

本轮根据用户对上一版的反馈重做第 2 步。采用 React、shadcn/ui Nova、Lucide、Motion、react-resizable-panels、dnd-kit 和 Zustand，源码位于 `frontend/`。此技术选择按用户最新要求执行，作为此前 Vue 设计安排的更新。

本地预览为 `http://127.0.0.1:5177`。从项目根目录运行。

```bash
npm --prefix frontend ci
npm --prefix frontend run dev
```

生产构建使用 `npm --prefix frontend run build`。此交付为高保真交互原型，使用演示内容和本地状态，模型生成与班级发布为模拟操作。

## 2. 组件来源与依赖约束

组件通过官方 shadcn CLI 4.23.0 获取，`components.json` 使用 `base-nova`、neutral 基础色与 lucide 图标。基础交互采用 Base UI，组件源码保存于 `frontend/src/components/ui/`，可以直接检查和调整。官方初始化和组件添加时采用已存在的 Vite 工程。[shadcn CLI](https://ui.shadcn.com/docs/cli)、[Vite 安装说明](https://ui.shadcn.com/docs/installation/vite)

|职责|采用的库及使用位置|
|---|---|
|界面组件|shadcn/ui Nova 与 Base UI，统一按钮、输入、弹窗、身份选择、页签、提示、抽屉、卡片和进度|
|图标|Lucide React，品牌标记、导航和所有操作图标共用|
|动画|Motion，页面进出、导航反馈、按钮、弹窗、提示与天平动作；遵循减少动态效果设置|
|可调整布局|react-resizable-panels，学习和备课的主辅工作区；窄屏切换为纵向内容|
|拖拽|`@dnd-kit/react` 的 sortable hook，用手柄调整教学活动顺序|
|状态|Zustand，教案、排序、目标、学生基础、截止日期、作答、提示状态、反馈与发布状态|
|构建与样式|React、TypeScript、Vite、Tailwind CSS 4，Nova 主题变量与项目布局样式|
|字体|本地打包的 Geist Variable，中文回退 Noto Sans CJK SC、Microsoft YaHei 与系统无衬线字体|

业务组件从 `@/components/ui/` 使用统一控件。CLI 归入开发依赖，额外动画样式依赖已移除，项目从 `motion/react` 引入动画。dnd-kit 的交互由自身传感器处理，排序项关闭额外 CSS 过渡。

锁文件检查覆盖 React、React DOM、Base UI、Lucide、Motion、Zustand、react-resizable-panels 和 dnd-kit，每项均为一个安装版本。当前依赖树中 Radix UI 包数量为零，`tw-animate-css` 已移除。官方组件使用的 `cn` 和 class-variance-authority 用于类名与变体组合。

## 3. 视觉系统

保持 Nova 的组件尺寸、控件形态、中性配色与焦点规则，统一三端。页面采用直接的功能标题、清晰的操作和状态，课程视觉采用专门生成的天平素材。

|维度|本版设计|
|---|---|
|基础表面|白色内容区、接近白色的侧栏与浅中性色边界|
|主要操作|Nova 深色按钮，次要操作使用 outline 或 ghost 变体|
|字体层级|页面标题约 28px，内容标题 19—29px，正文 13—14px，辅助信息 11—12px|
|强调方式|课时插图、当前学习入口、目标进度和业务状态；主操作保持中性|
|桌面框架|224px 侧栏、65px 顶栏、统一主内容边距；首页主列与辅助列分工|
|手机框架|收起侧栏，通过 Sheet 展开；首页图文上下排列，学习与备课纵向展开|
|课程视觉|AI 生成天平与砝码的课程插图，原图保存于 `frontend/public/images/equation-balance.png`|
|图文关系|桌面左侧阅读与操作、右侧课程图像；手机端将图像放到阅读区之后|

首要内容由“继续学习”的真实操作和等式性质问题承载。备课页直接呈现教师教案与配套学生内容，活动顺序实时对应。学习页将教学内容、天平操作、解释输入和帮助组织成工作区。

## 4. 本轮文案精简

页面标题使用“我的学习”“教学案例”“独立检查”等功能名称。删除首页口号、页头副标题、侧栏宣传区、页脚口号、重复的进度解释和区块帮助段落，按删减后的内容量调整课程主区与侧栏间距。

必要的来源说明、演示范围与独立检查规则使用带可访问名称的 info 按钮及 tooltip。按钮支持键盘聚焦，触屏界面保留可点击入口。页面整体以一个“演示”标记说明数据性质。

表单继续保留可见标签或明确的可访问名称，弹窗简短说明通过读屏关联。课程讲解、题干、实际教师反馈和原始资料属于任务内容。发布确认保留具体后果提示，明确发布后学生可从班级任务进入本课。

主要操作使用“继续学习”“订正”“开始检查”“发布任务”等动词。原“保存并稍后继续”入口按实际行为改为“查看本课结果”。

## 5. 页面与实际交互

|页面组|原型路由|主要行为|
|---|---|---|
|学生首页与课程|`#home`、`#courses`|继续学习、教师任务、复习、课程入口与目标进度|
|学习与检查|`#learn`、`#check`、`#result`|调整主辅面板、操作天平、解释保存、预设答疑、求助后换新题、提交结果|
|错题帮|`#wrong`、`#repair`|分类查看、选择原图并确认题目、回看原作答、变式与返回任务|
|案例阅读|`#cases`、`#case-detail`|关键词查找、收藏、阅读引导方式及适用条件、进入备课|
|备课与任务|`#prepare`、`#class`|活动文本编辑、拖拽排序、对应学生预览、局部模拟生成、选班级发布|
|教师学情|`#teacher`、`#insights`|概览、原作答与帮助时间线、独立表现、修改反馈和安排补充学习|
|内容管理|`#manage`、`#content`、`#issues`|材料与经验对照、案例草稿、核对发布、关联课时、反馈处理和失败重试|
|辅助入口|`#records`、全局搜索、消息、帮助|历史尝试、搜索跳转、通知定位和本次浏览会话反馈|

独立检查继续采用已确认的规则。帮助绑定当前尝试，进入下一题后重新记录是否独立完成。教师教案与学生预览共享同一活动顺序，拖拽后由 Zustand 保存。教师反馈可在学生本课结果中读取。

演示班级的三名学生记录与当前用户的本地作答分别展示，统计从对应数据计算。例题仍采用等式性质的固定自编题目，原型数值判断与说明明确显示。用户录入的自定义题目可以保存，补救内容当前采用固定例题。

## 6. 自审维度和修订记录

本轮使用 design-taste-frontend 的应用界面与截图评审指导、frontend-design 的内容与视觉规则、ui-ux-pro-max 的交互检查、information-architect 的既有页面结构、imagegen 的课程素材生成，以及 verification-before-completion 的完成证据要求。Nova 及用户指定组件体系作为统一设计依据。

本轮按用户指定的 typography、whitespace、visual hierarchy、color、motion、micro interaction、responsive、originality 八项进行截图与操作检查。奖项网站作为视觉参照，最终美感由用户验收。

|检查维度|观察与修订|
|---|---|
|字体|从上一版接近的字级调整为页面标题、教学问题、正文与辅助层级；本地加载 Geist，中文使用无衬线字体；提高辅助文字对比|
|留白|减少学习助手底部的无用途空区，将输入放到桌面面板下方；课程、任务与复习使用不同层级的分组间距|
|视觉层级|首页学习主入口搭配课程图像；任务列表承担直接操作；右栏承载目标进度与下一步|
|色彩|Nova 中性控件统一三端；课程素材使用紫蓝与金色，状态色按业务含义使用；正文回到可阅读的中性文字|
|动画|使用 Motion 完成进出与操作反馈，移除额外动画依赖及官方源码中的 CSS 动画类；尊重减少动态效果设置|
|微交互|按钮、页签、收藏、预览、保存、发布、拖动手柄与消息均有对应反馈；减少状态不明的操作|
|响应式|在 1440px、768px、390px 检查；修正手机首页图文挤压、学情表头隐藏文字导致的横向溢出；桌面和平板保留表格，手机转换为完整学生记录卡|
|原创性|天平课程素材与可操作教具围绕等式目标设计，教案与学生活动并列同步；内容来自当前教学流程|

第一轮识别首页手机图文挤压与学习助手空区，完成布局修订。第二轮发现学情页窄屏溢出，定位到表头辅助文字的绝对定位超出滚动边界，补充滚动容器的定位范围。随后重新检查全部页面和关键操作。

参照资料包括 shadcn Nova 官方创建入口、Webby 教育与学习类获奖目录，以及 FWA 官方作品入口。Awwwards 多个作品页抓取失败，当前未获得其完整实时页面。此处记录实际可访问的参照范围，奖项标准作为本轮设计目标。[Nova 创建入口](https://ui.shadcn.com/create)、[Webby 教育与学习类目录](https://winners.webbyawards.com/winners/apps-software-immersive/consumer-apps/education-culture-learning)、[FWA 官方入口](https://thefwa.com/)

## 8. 后续衔接

这一版 React 原型可直接作为第 3 步前端工程的基础。界面组件、布局、状态和课程素材均在项目内，后续逐页接入真实业务 API 与 MySQL 数据。旧静态原型保留用于前后对照，当前设计以本文件和 `frontend/` 为准。

本轮交付完成视觉重做与原型交互，实际模型调用、真实班级通知、完整题目生成和服务端持久化随后续步骤实现。图片选择用于当前页面预览，学生真实上传资料的持久保存将在业务接入时完成。
