# 师承智学前端视觉与交互设计

日期 2026-11-07　版本 v4

## 当前技术栈

按用户最新要求，前端整体迁移为 Vue 3 + JavaScript。页面、路由、公共组件和本地状态已替换；删除 React、TS/TSX 源码、TS 配置及对应直接依赖。项目自行维护的前端源文件使用 `.vue`、`.js` 和 `.css`。

|职责|当前实现|
|---|---|
|工程与路由|Vue 3、JavaScript、Vite、Vue Router；哈希路由 `#/home`，首次进入旧 `#home` 链接会规范化|
|界面组件|官方 shadcn-vue CLI 生成 JavaScript 组件，底层 Reka UI；组件源码位于 `frontend/src/components/ui/`|
|视觉语言|保留既有 Nova 中性色、布局、字号、课程图像和控件形态，统一三端|
|图标|`lucide-vue-next`，只保留这一套 Lucide 包|
|动画|`motion-v`，页面、按钮、提示、天平和弹窗；遵循减少动态效果偏好|
|可调整布局|Reka UI Splitter，学习及备课桌面双栏；平板和手机纵向排列|
|拖拽|VueDraggable / SortableJS，备课活动手柄排序，同时支持手柄上下方向键|
|状态|Pinia，浏览器本地保存；读取旧 Zustand 存储中的教案、作答、收藏与反馈|
|样式与字体|Tailwind CSS 4、共享主题变量、项目布局 CSS、本地 Geist Variable 与中文系统字体|

shadcn-vue 的当前组件配置使用 `new-york` 和 `typescript: false`，再通过共享主题与布局适配既有 Nova 视觉；未将其称为官方 Vue Nova 预设。原 React 专用的 Base UI、Zustand、react-resizable-panels、dnd-kit 已移除，以对应 Vue 库承担原有职责。保留 `cn` 与 class-variance-authority 处理组件类名，不再重复直接安装 clsx、tailwind-merge 或第二套图标库。

组件来源：[shadcn-vue 配置](https://www.shadcn-vue.com/docs/components-json)、[JavaScript 组件说明](https://www.shadcn-vue.com/docs/javascript)、[Reka Splitter](https://reka-ui.com/docs/components/splitter)、[Motion for Vue](https://motion.dev/docs/vue)。

## 视觉与文案

沿用白色内容区、浅中性侧栏、深色主操作、少量紫蓝和金色课程视觉。首页以课程封面和继续学习为主；备课页并列教案编辑与学生预览；手机端学情表格呈现为完整学生记录卡。保留课程天平图像 `frontend/public/images/equation-balance.png`。

继续采用简短功能标题和直接的操作名称，不加入口号、区块说明或重复状态解释。来源、演示范围和操作补充使用 info + tooltip；保留可见表单标签、可访问名称、焦点状态及发布后果提示。教学讲解、题干、教师反馈和资料原文作为必要内容保留。

## 页面与交互

|页面组|路由|可用行为|
|---|---|---|
|首页与课程|`#/home`、`#/courses`、`#/teacher`|继续学习或备课、任务跳转、课时入口与进度|
|学习与检查|`#/learn`、`#/check`、`#/result`|调整工作区、天平操作、解释保存、预设答疑、独立作答与结果提交|
|错题帮|`#/wrong`、`#/repair`|分类查看、题目及原图录入预览、固定变式作答、返回任务|
|案例|`#/cases`、`#/case-detail`|搜索、收藏、案例阅读与备课入口|
|备课与班级|`#/prepare`、`#/class`|编辑目标和活动、排序、学生预览、模拟生成、选择班级发布、演示邀请口令|
|学情|`#/insights`|演示学生过程、反馈编辑并回流学生结果、模拟安排补充学习|
|管理|`#/manage`、`#/content`、`#/issues`|资料选择、案例编辑与会话草稿恢复、核对发布、课时关联、反馈处理与重试|
|其他|`#/records`、搜索、消息与帮助|历史尝试、内容跳转、反馈入口|

独立检查的提示绑定当前题，换新题后重置；作答保留原答案、解释和是否获得帮助。教案与预览共享同一活动数组，排序和内容同步。教师反馈与学生结果共享同一状态。

新存储键为 `shicheng-vue-prototype`，没有新记录时读取 `shicheng-nova-prototype-v2` 中的旧记录，保留旧键。选择的原图用于当前浏览会话，尚未接入服务端文件保存。

```bash
npm --prefix frontend run build
```
