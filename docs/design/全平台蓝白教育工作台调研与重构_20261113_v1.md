# 全平台蓝白教育工作台调研与重构

2026-11-13 / v1 / 用户已选择“蓝白教育工作台”

## 结论与实施范围

平台以“完成当前教学任务”为核心组织内容。学生先看到下一项学习、练习或订正；教师先处理备课、发布和反馈；管理员围绕材料与课程维护工作。三端共用蓝白主题、中文字体、导航层级和组件规格，使用同一套Element Plus。

本轮落实全站外壳、字体与阅读层级，重排首页、课程、错题筛选、备课、班级、学情及管理编辑区。保留现有真实注册、登录、MySQL数据与业务逻辑。没有将每个业务组件都推倒重写；课堂、考试、社区、复习等页面通过统一外壳与排版规则同步更新，其已有业务交互继续复用。

## 当前代码的具体问题

1. 历史样式逐轮追加，字体栈和字号定义分散，页面之间缺少稳定规则。
2. 原Geist不提供完整中文，中文依赖各主机回退字体，同一页面中英文观感分离。
3. 同时存在侧栏、分类卡片和业务页签，导航重复占据垂直空间。
4. 部分列表仍按旧按钮尺寸排版，消息、课程和最近提交的长标题容易挤压。
5. 备课、课程维护和学习阅读使用近似字号，但三种任务的阅读需求不同。
6. 管理课程主区与背景同色，编辑对象边界较弱。

## 已落地的统一规则

- 字体：本地加载Noto Sans SC Variable，移除Geist字体依赖，中文和英文共用字体体系；数学专用符号仍按其表达需要使用数学字体。
- 颜色：主蓝#2f64d6；页面#f3f6fb；白色内容区；正文#354861、标题#182b49、次要文字#62748d；状态继续使用语义色和文字。
- 排版：页面标题26px/600；区块18px/600；一般标题16px/500；界面正文15px；表格与表单14px；学习正文18px/1.8。
- 布局：桌面侧栏224px，顶栏64px；页面边距28px，大屏36px；主辅区间距24px，卡片使用官方边框与圆角。
- 导航：主侧栏按工作组织；分类改用直接ElTabs，去掉外层导航卡片；页面只保留一个主要标题。
- 输入与按钮：普通操作36px，紧凑操作30px；登录表单44px与切换页签48px继续保留。
- 文案：“课堂说明”改“课堂讲稿”，“学生正文”改“学生看到的内容”；学情列“独立检查”改“独立练习”；学生复习入口统一名称。没有删除教学正文、答案、来源及必要条件。

## 持续维护入口

全站主题与尺寸规则集中到frontend/src/education-workspace.css，由main.js最后加载。后续改主题优先修改此文件和Element Plus变量，避免再次在多份历史样式中分别更改字体与尺寸。

历史页面的业务排版仍在对应样式文件中保留，逐页业务迭代时按实际复用继续整理；本轮没有为了清理样式删除不确定的业务布局。组件源码与路由仍可直接维护，不引入React或TypeScript。
