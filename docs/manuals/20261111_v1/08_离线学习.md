# 离线学习

1. 联网登录学生账号，从侧栏进入“离线学习”。首次使用设置至少8位独立本机口令，保存好；不是服务器密码。
2. 选择本人授权课时，点击下载。全部文本和图片成功后才保存。仅下载当前支持的普通学习任务，不承诺考试离线提交或离线模型指导。
3. 断网后从登录页“打开本机离线学习”进入，输入原账号与离线口令解锁。浏览器重启后也需重新解锁。
4. 阅读、保存位置或填写答案和过程，再“保存本机草稿”。此时只是本机保存，尚未正式提交。
5. 恢复网络，以同一账号检查学习服务，再同步草稿。版本或双端修改冲突先对比，由用户确认；撤回、截止、移出班级或已提交任务只能保留副本。
6. 同步成功后“返回在线学习与提交”，核对答案，按正常课程流程完成作答及提交。

本机包授权最长72小时，断网不能实时知道教师之后的撤回。服务器始终在同步时重新核对身份、成员和任务状态。同一操作重复同步不重复写入；本机保存不覆盖正式作答。

退出可选择保留加密下载；默认清除当前账号本机数据。忘记口令不能恢复密文。清除全部下载会删除未同步草稿，操作前确认。
