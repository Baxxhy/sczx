# 备份、恢复与回滚

## 一致备份

停止目标所有业务写入者，等待模型任务结束。仅停工具自身PID不够；外部连接、同库Python进程或未完成模型任务会阻止备份。

python deploy/manage.py backup --env 私有配置 --output 新备份目录

备份包含database.sql、uploads.tar.gz、release.tar.gz、config.env.example和release.json。清单含版本、时间、整表行摘要、每个上传的字节数和SHA256。私有配置、SQL、原图包和凭据不推送GitHub。目录0700、文件0600，完成后再次校验。

## 恢复

创建新的空MySQL库和空上传目录，使用匹配发布代码及新配置。

python deploy/manage.py restore --env 新私有配置 --archive 完整备份目录
python deploy/manage.py check --env 新私有配置
python deploy/manage.py start --env 新私有配置

恢复拒绝非空库/目录，不删除现有资料。除了导入成功，还需核对全部行摘要、原图字节，再登录读取班级、课时、原答、考试、课堂、教研和离线记录。失败副本保留，不能覆盖重试。

## 回滚

新代码启动失败先停止该新进程，保存service.log、journal和迁移日志。先备份升级后的库及上传以保留新增数据。将升级前备份恢复到另一个空库，使用升级前配套代码和构建验证；经批准才切换服务指向恢复库。禁止直接在正式库执行不可验证downgrade。
