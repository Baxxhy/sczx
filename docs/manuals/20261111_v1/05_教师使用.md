# 教师使用

1. 登录教师账号，建立班级，生成邀请或添加已有学生；确认年级、学科与成员后发布任务。
2. 检索案例，选择年级/学科/知识点。明确筛选严格生效；前置知识只扩展一层。查看原文和案例版本，再“用于备课”。
3. 选择发布课时。AI备课填写具体教学任务；结果只是建议。编辑目标和活动，核对来源与数学后确认保存到备课草稿；草稿变更会提示冲突。
4. 保存教案版本，打开学生预览，检查活动顺序、题目和截止日期，再选择班级确认发布。发布快照不会被后续草稿改动。
5. 学情页查看本人班级原答、解释、求助、补救和独立题。一次正确不称掌握；两道不同题独立正确只表示已有独立正确证据。
6. 针对实际错题发补充学习，学生开始/提交后查看新证据并发送反馈。固定示例与本轮交付合成数据都有验收名称，不代表真实教学效果。
7. 题库审核题目版本，按约束组卷并审核后发布考试。核对自动结果，应用题过程需人工批阅。成绩发布后学生才能查看评分和答案。
8. 课堂推题后看真实提交人数，结束保存历史。分层安排可人工调整为补基础、巩固、拓展或证据不足；组别不作为永久能力标签。
9. 教研分享指定发布版本，收藏、讨论或借鉴；保留来源，不改变原作者版本。
