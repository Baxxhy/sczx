# 管理员使用

1. 登录管理员账号，从账号管理创建教师与学生。教师自行建班，避免共用一个账号操作所有角色。
2. 进入“资料与案例”，上传PDF、DOCX或题图，填写材料名、作者和来源。等待解析完成，打开原文位置，核对公式与识别文本。
3. 选原文片段创建或提取案例，编辑教学目标、活动、教师提问、可能回应与适用边界。数学核验只覆盖列出的表达式，不等于全文教学审查。
4. 保存后核对原文和内容，再审核发布；任何编辑会撤销原审核。发布生成新版本，历史任务继续使用快照。
5. 在课程内容管理维护知识点与课时，核对参考答案和不能除零等条件。验证、审核后发布，旧版本保留。
6. 从反馈与运行页查看问题、解析失败和模型错误。先看实际错误再重试，避免重复上传或重新发布。

管理员看运行任务不等于拥有学生私人作答的任意读取权限。误操作撤回时保留历史版本；删除或永久变更前核对后果提示。
