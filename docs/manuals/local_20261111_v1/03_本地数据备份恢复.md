# 本地数据、备份与恢复

backend-business/var/local包含本软件专用MySQL数据、上传、local.json、local.env、accounts.json、日志与备份。该目录被Git忽略且限制权限，不能当作可随意删除的缓存。浏览器自己的离线下载另存IndexedDB，清理网站数据会删除它们。

./start-local.sh backup

命令短暂停止本软件网页，生成SQL、上传包、配置模板、账号私有副本与校验清单，检查数据一致后恢复原运行状态。备份路径在输出中，不向GitHub提交SQL、密码或用户原图。

./start-local.sh restore --archive 完整备份目录

恢复到新建的独立本地数据库和新上传目录，逐表、逐文件核对，再切换本地配置；原库和原文件保留，已有服务按原运行状态恢复。不会覆盖非空目标，也不访问原项目的正式库。

数据恢复后实际登录检查课程、原答、反馈与文件。代码和依赖对应版本从GitHub保存；记录使用的提交，不把只有数据库的备份当作Python/Node安装环境。

本轮实测启停、重复启动、新库恢复、账号和五课记录保持。6个误写测试文件已按用户批准核对引用和哈希后可逆保留，82个原文件未动。
