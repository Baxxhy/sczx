# 常见问题

打不开网页：执行doctor，再查看logs/service.log。确认8099与专用MySQL端口可用，当前目录和--home一致；不要去修改其他软件的数据库。

登录失败：从本机私有accounts.json核对账号；默认全新安装为admin、teacher、student，当前导入示例使用handoff前缀。不同角色分开登录，不共享同一账号操作所有角色。

AI超时：检查同一运行账号的Codex登录、PATH和网络。任务自动有限重试后可手动重试；保留原问题和结果。若依赖终端代理，在私有配置明确继承，不使用备用OpenAI凭据。

语音没有结果：已在真实非无头浏览器尝试；当前识别返回没有听清，系统没有可用中文朗读声音。继续输入或阅读文字，原文本不会被清空。V01/V03仍未完成物理发声与听检，不把组件模拟测试当作真实识别/扬声器通过。

数学需核对：程序只核验支持的数值或表达式，不把应用建模和解释自动判成正确。原答案与帮助记录保留，老师可核对。

离线冲突：重新登录原账号检查服务，逐项对比后确认同步。已提交、撤回、截止或移出班级不能绕过。忘记离线口令不能恢复密文，清除前先保存需要保留的草稿。

本地数据库不兼容：启动只报错不迁移；保存备份与日志，按版本说明在独立副本核验。不要删除数据目录重装来掩盖问题。
