# 启动、停止与诊断

在项目根目录运行：

./start-local.sh

打开 http://127.0.0.1:8099 。同一命令会启动本软件专用MySQL及网页服务；重复启动复用已有进程，不重复创建账号或发布示例。关闭终端后服务继续运行。

./stop-local.sh

停止本软件网页及专用MySQL，保留数据库、上传、账号与草稿。再次运行start-local.sh继续使用。不会停止原23317数据库或其他项目。

./start-local.sh status
./start-local.sh doctor

查看网页、数据库、前端构建、Codex路径及账号文件位置。运行日志在backend-business/var/local/logs，MySQL日志在该目录下mysql/error.log，不需要安装正式systemd或配置公网HTTPS。

端口占用时不会接管别人的服务。首次init可用--port和--mysql-port指定空闲端口；独立验收副本用--home指定另一目录，日常操作需持续使用同一个home。

更新前先备份，停止后运行安装脚本重新装依赖并构建，再启动。启动不会悄悄升级不兼容数据库；本地版本问题保留日志，按对应版本说明处理。
