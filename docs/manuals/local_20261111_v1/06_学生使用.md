# 学生使用

1. 使用自己的账号登录，通过教师邀请加入班级。在课程页进入本人已发布任务。
2. 依次阅读课时、操作互动教具，填写自己的解释。保存进度，刷新后继续。数学工具只允许规定运算，除数不能为零。
3. 不会时先请求提示；题图先上传，核对OCR并修订确认，再进入文字指导。求助会记在当前题和尝试，不能清除为独立完成。
4. 普通练习和独立检查分别提交，保留原答与过程。完成必需活动后到结果页“提交本课结果”。保存草稿不等于正式提交。
5. 错题页查看来源任务与原始作答，核对错误原因，再订正、做新变式、完成独立复测。新题重新记录帮助，原错不会被新答案覆盖。
6. 学习记忆只展示已保存证据与复习建议；查看教师反馈后返回相应任务。
7. 考试先保存草稿，检查后提交；以服务端截止时间为准，提交后原答只读。教师发布成绩后查看讲评，再补救考试错题。

无法自动核验的输入显示需核对，不应将它当作正确。需要帮助时保留具体问题、任务和题号。
