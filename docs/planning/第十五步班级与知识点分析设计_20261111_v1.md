# 班级与知识点分析

2026-11-11，v1。

GET /api/insights?classId=…&taskId=…&start=…&end=…返回有权限的当前班级投影。前端ClassAnalytics复用现有学情页，按知识点、题目、学生、待核对及教学安排切换；三种桌面宽度共用Nova、现有字体和组件，无新增依赖或装饰性图表。

知识点显示全班分母、作答/核验/独立错误/需要补强/证据不足/复测人数。共性问题只描述实际事件人数，可打开原答、解释、版本和时间；不判断数学思维、能力或预测成绩。无事实显示0或证据不足。

学生详情显示分配/提交/反馈及原始学习过程，链接既有LearningMemory读取知识状态、错因、帮助、补救和建议。没有另建画像表。题目使用LearningTask.questions与lessonSnapshot版本，保留每次原始作答，汇总按学生去重。来源入口打开原任务及原学生。

未核验作答、学生解释和未处理关联请求集中展示；人工确认或退回通过既有LearningMemoryChange追加观察，原答案和程序结论不覆盖，关联修订继续在学习记忆页完成。人工记录显示已核对/待补充，不冒充自动评分。

筛选保留URL；insights按路径维持组件，避免仅更新筛选就重建页面关闭弹窗。迟到班级响应按请求代次丢弃，加载期间不呈现旧班可操作数据；离线可重新读取。
