# 第十二步完整业务验收报告

日期2026-11-10，版本v1。阶段A 3/3，阶段B 24/24通过。第十二步完成，第十三步可以开始但本轮未执行。

## 结果

本轮复用原学生工作区、OCR、ModelJob、求助记录、检索和知识关系，完成提示/举例/换讲法/补基础/自主尝试及有限多轮LangGraph。每轮固定本人任务、课时版本、块、题、实际问题/回应、题图确认及来源；最多4轮历史、24k模型输入、一次主要生成和一次针对性修订。问题超3000、确认文字超6000或公式超500明确拒绝，不静默覆盖原始输入。自主尝试0模型调用，不清空帮助。

复现移出学生重试返回200，修复为403；真实运行中移出后结果不写回，原请求与历史保留。修复题号和未提交答案只初始化一次、旧上传后到、OCR失败改文字残留图片及同请求重放问题。阅读组件通用完成绕过未复现，既有后端依真实作答的规则保留，新增伪造完成标记测试。

真实网页以教师发布开始，学生完成阅读、活动、随堂题、5种指导及回应、独立新题、本课提交、原图识别和修订确认；教师读到实际过程并反馈，学生重入读取。两个教师、不同班级、至少3名学生、两个课时和两个知识点实际检查，历史只读另验。受控中断通过真实恢复函数变为failed，再用真实Codex手动重试成功；实际运行中移出和结束任务也通过。断网草稿恢复与题目求助自动聚焦通过。

## 复核与集中修订

首轮实现及初验后集中修订发现的问题：数值扫描误截变量式后缀、任务/题图作用域、重复请求、失败计量、过长上下文、图片fallback及助手窄栏。最后复核图片指导发现确认的3z=18仍受原题2(a-1)=10影响，修复context.focus并使新图父轮隔离，重新上传、确认、生成、刷新、教师查看及反馈5步通过。旧坏样例在隔离库和原日志保留，不作为最终通过证据，也没有导入正式业务数据。最后保持源码冻结，没有扩展第十三步。

初验测试run命名覆盖unittest入口曾让新增8项未运行，后续修正并以实际54项为最终数；没有把初验42项当成新套件完成。浏览器弹窗选择器失败属于脚本错误，修正后重新执行。完整初验与终验见audit-issues。
