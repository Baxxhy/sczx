# 错题补救流程与评分

2026-11-10，v1。

错题帮独立查询当前账号全部错题。来源分为课程作答、个人手动录入及题图识别。录图先上传原图，可另存矩形裁剪，OCR 后人工修改文字/公式并确认单道题；保留 OCR 原结果与确认版本。

补救顺序：查看原作答 → 分析可能错因 → 学生确认或修改分类 → 读分步订正并回答检查问题 → 针对回应继续指导 → 有帮助的变式练习 → 独立新题 → 保存实际作答及核验 → 回到原任务或个人列表。

分析使用原题、原答案、原解释、确认错因、真实知识点和一层前置知识。建议证据必须逐字来自原答案或解释；缺失时留空并说明不确定性，不当作能力诊断。多轮指导复用 tutoring 的最多4轮、五种策略、数学拦截及来源约束，父轮必须属于同一错题。模型调用继续为 Codex gpt-6-luna/low。

变式仅自动接收有完整条件的单变量、单解实数方程；保留括号或常数分母结构，改变数值及答案，拒绝原题、已生成题和只换字母的同答案。生成时程序解方程，比较模型参考值；题干泄露答案、已知数学错误或原题条件不确定时阻断自动评分。概念类问题可以分析和订正，暂不自动生成选择/文字评分题。

| 核验结果 | 含义 |
| --- | --- |
| verified_correct | 实际变式的解与学生答案经符号核对等价 |
| verified_incorrect | 可解析但与实际变式的解不一致 |
| unverified | 答案、条件或表达超出核验范围，保存原作答并等待人工核对 |

独立复测须有本题补救方案及一条新版练习记录。独立新题重新作答；原帮助记录不清除。在新题生成后发起本题指导，即使客户端没有勾选帮助，也由服务端记 helped。一次变式只能提交一次实际答案；网络重放返回同一记录，重新尝试需生成另一道题。教师人工结论单独保存，不伪装为程序已验证。

列表状态从实际记录计算：待补救、补救中、待独立复测、独立复测通过/未通过、需要核对。独立复测通过只表示这一道新题无帮助且核验正确，不等于彻底掌握。历史固定示例的“正确”不进入新版复测状态。

接口统一在 frontend/src/services/wrongs.js；后端 remediation.py 提供列表、详情、录题、分类/草稿、作答及教师核对。原课程 repairs 接口兼容到同一评分服务，必须提供真实变式关联，不再使用全局固定方程。
