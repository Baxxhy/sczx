# 第五步实施与验收

日期 2026-11-08　版本 v3

状态：本轮替代方案已实现。真实 BM25 案例检索、Codex 语义重排与学生指导通过；浏览器语音控件及回退已验证。当前无头环境缺少中文声音，真实设备的麦克风识别与声音播放尚未验收。原六类外部 API 验收不等同于本轮替代方案。

## 当前确认范围

用户在要求统一使用 Codex CLI、gpt-6-luna、最低 low 思考强度后，进一步要求“检索那里换一个算法……这个全改了”。本轮采用 BM25 替代向量检索，并将语音入口改成浏览器语音输入和朗读。用户随后明确只做桌面 Web，本轮以 1440、1920、2560px 网页布局和鼠标键盘操作为交付目标。保留 Vue 3 + JavaScript、现有 Nova 界面、FastAPI + MySQL、原图和历史记录；不使用备用 OPENAI 凭据，不部署本地模型。

历史 HTTP 接入与 CLI 切换过程可在 Git `3b9c122`、`3171d83` 查看；当前使用说明见[第五步使用与实现说明](第五步使用与实现说明_20261108_v3.md)。最初提示词保留作为阶段来源，当前接入范围以用户后续要求和本记录为准。

## 实现

- `retrieval.py`：中文二元组 BM25，匹配真实已发布案例，无向量和新依赖；查询未命中返回空结果。
- 新增案例检索和按 ID 读取接口；教师搜索、阅读、详情刷新和选定案例备课使用实际内容，移除原硬编码字符串匹配；桌面宽屏采用双列案例和固定宽度右栏。
- 新增持久化 `retrieval` 作业，支持 BM25 后 Codex 重排；重排失败保留 BM25 结果并明确提示，案例内容作为运行快照保存。
- 学生求助从已发布案例中检索最多三篇，将快照传给 CLI；结果与教师回看保留关联案例名称及来源。案例关联不代表教师认证或教学成效证明。
- `SpeechInput.vue`：浏览器语音输入、临时文字预览、确认文字追加、错误提示、题目切换和卸载清理；不自动发送。
- `SpeechReader.vue`：设备中文声音检测、分段朗读、暂停、继续、停止、单处朗读与卸载清理；无声音时提示阅读文字。
- 管理端六个入口更新为文字指导、OCR、案例检索、材料重排、语音输入、文字朗读；历史向量和上传音频任务仍可读取，当前不调用 CLI 伪造不支持的模态。
- 未新增数据库迁移、运行依赖、React/TS 源码或项目测试文件；无关工作区改动保持原状。

## 已知范围

- 浏览器识别依赖设备权限及服务连通性，浏览器朗读依赖声音资源；当前服务器环境不能证明真实麦克风识别或中文声音输出成功。没有使用生成文本、受控事件或公开样本播放冒充语音模型验收。
- 浏览器朗读不提供合成文件，浏览器语音输入不等于任意音频文件转写。历史原图、上传文件、作答、教师反馈和旧模型结果保留。
- BM25 是当前规模下的词汇检索，后续可按实际语料增加分块与混合召回；本轮未建设完整 RAG 内容加工或 Agent 教学编排。
