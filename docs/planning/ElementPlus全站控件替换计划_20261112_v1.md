# Element Plus全站控件替换计划

2026-11-12 / v1

本轮范围是整个前端。使用executing-plans持续跟踪：

1. 移除剩余38处原生按钮实现，使用官方按钮和选中状态；链接、表单、数字输入和图片显示也统一。
2. 将仍由HTML与CSS绘制的内容框、列表卡片、讲稿区域、学习/补救框改用ElCard；布局继续承担页面组织，清理旧边框、背景、选中皮肤。
3. 图片裁剪显示使用ElImage、数值调整使用ElInputNumber，保持原图、指针选区和Canvas裁剪逻辑；坐标与真实图像区域对齐。
4. 检查导航、工具提示、消息、确认框、modal、图标、表格、加载、空状态及业务适配层实际底层组件，不再存在平行的自绘基础控件。
5. 完成源码清单、自动检查、三端逐页浏览器与真实交互返修、构建、本地8099检查及提交推送。

完成标准：源码没有原生交互控件和自绘通用框；对应控件实际渲染为Element Plus，旧数据和操作保持。教学数据、计算算法、页面排版及浏览器媒体能力属于业务逻辑，不另造基础控件。

进度：五项均完成。补充完成官方ElTree拖拽、音频控制、页面区域边界与消息重叠修复，详见同目录《ElementPlus全站统一与区域边界验收_20261112_v1.md》。
