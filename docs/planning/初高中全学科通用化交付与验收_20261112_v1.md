# 初高中全学科通用化交付与验收

2026-11-12 / v1 / 本地网页软件

本轮将课程、题库、作答、错题和AI从“一元一次方程专用”改为按实际年级、学科和题型工作。原数学五课、任务快照和历史记录保留。支持录入与使用各科内容，尚未内置六个年级所有教材、题库和教学资源。

## 已交付能力

| 环节 | 当前行为 |
| --- | --- |
| 学科与年级 | 七至九年级、高一至高三；19个常见学科预设，允许输入其他学科。学科配置由后端统一提供 |
| 建课与发布 | 创建课程时选择年级、学科；新课时继承课程信息。语文、英语等课时无需方程即可核对、发布，支持讲解、例题、讨论探究、练习、图片 |
| 题目编辑 | 13类题型：单选、多选、判断、填空、简答、论述、计算、证明、阅读、写作、翻译、实验分析、程序与算法 |
| 学生作答 | 选择题使用实际选项，主观题使用多行输入；答案和依据保存、刷新恢复、提交与教师反馈沿用现有流程 |
| 核对规则 | 客观题按教师配置答案核对；数学仅在程序支持范围核对；开放题等待教师评阅。主观答案未程序核对不自动记为错题 |
| 课程浏览 | 按年级、学科筛选真实已发布课程；没有资料的科目显示空状态，不伪造课程与学习任务 |
| 我的错题 | 可选择学科年级，保留原题与原图。来源任务自动携带实际学科；个人录入不继承当前数学任务的学科 |
| AI服务 | 指导、备课、候选题、OCR和补救携带实际学科年级。通用新题允许没有方程；主观补救可提交并等待教师核对 |
| 数学专属功能 | 一元一次方程规则按实际学科与内容附加；其他学科不强加天平、共同运算或单变量求解。人工评阅函数题不显示方程变形工具 |
| 考试与课堂 | 复用同一作答组件；题库、学生试卷、原答和导出保留选项，教师评分继续使用原流程 |

## 提示词的位置与调用

- `backend-business/sczx_business/prompts/general.md`：全科通用教学、依据、追问及结构化输出要求。
- `backend-business/sczx_business/prompts/subjects.json`：语文、数学、外语、理化生、史地政、信息技术、艺术、体育及实践等分科指导规则。
- `backend-business/sczx_business/prompts/linear_equation.md`：一元一次方程专项附加规则。
- `backend-business/sczx_business/subject_prompts.py`：根据实际请求上下文组合提示词；CLI及API通道复用。

现有Codex CLI仍使用gpt-6-luna、low。全科配置供实际任务调用，不在后台批量生成并发布空壳教材。模型生成的题目、案例与教案继续经过既有人工确认流程；不同表达不自动视为错误。

## 发现并修复的问题

1. 发布课时强制要求单解方程，改为依据题型和核对模式验证。
2. 新建课时固定为七年级数学，改为继承课程。
3. 选择题缺少可操作选项、写作只有单行，改为统一题型组件。
4. 普通作答被数值判分路径处理，改为客观匹配、数学核对和人工评阅三种明确模式。
5. 新增讨论内容无法完成，补齐输入门槛与完成记录，并纳入浏览器回归。
6. 函数题误显示方程变形工具，改为仅数学核对题显示，并实际回看页面。
7. AI结构中的自由对象选项导致结构化请求失败，改为明确的选项结构；随后模型返回中文题型标识，再以题型枚举约束并重试成功。
8. 教师AI备课请求遗漏学科、默认提示仍讲等式、发布说明仍声称已核对方程，分别改为实际学科与核对范围。

## 使用入口与范围

本地入口沿用 `http://127.0.0.1:8099`，账号沿用已有账号。管理员在“课程内容”新建课程，选择年级/学科后新建单元与课时；教师选用真实已发布课时发布班级任务，学生从学习任务进入。

跨学科工程验收使用独立测试库及自编材料，不写入实际使用库，不代表教师评审或课堂效果。还需按实际教材录入、生成并审核各科资源；不会因为支持某个学科就宣称已经收录其全部教学内容。语音设备例外继续沿用此前记录，本轮未以虚拟音频替代实机验收。

## 重复检查入口

浏览器组件检查：`npm --prefix frontend test`；JS检查：`npm --prefix frontend run test:unit`；构建：`.venv/bin/python deploy/build_frontend.py`。

后端使用`.venv/bin/python -m unittest discover -s backend-business/tests -v`，设置`PYTHONPATH=backend-business`。MySQL业务检查必须另外指向新建的`sczx_test_`隔离库并设置`SCZX_RUN_MYSQL_TESTS=1`；不对实际使用库运行测试种子。无MySQL时被跳过的检查不能记为业务通过。
