## 第二组：第九步教师备课Agent

- 入口沿用备课工作台，Vue＋JS/Nova；不新增聊天机器人。当前课时、教师目标/困难/限制作为输入，规则识别活动设计、误解纠正、补基础任务，明确展示识别结果。
- 通过LangGraph组织不超过6个主要步骤：上下文 → 案例检索 → 原文材料检索 → 结构化生成 → 程序核验 → 待教师确认。只允许这些白名单工具，没有模型执行任意代码或无限工具循环。
- 复用ModelJob/Run/Event与SSE，逐步结果保存到同一任务JSON。重启保留已完成节点，手动重试从检查点继续，不重复调用已成功模型步骤。总时限和单节点时限有界，最多一次自动结构修复/重试；默认不调用重排。
- Codex gpt-6-luna/low增加结构化备课输出；当前课程、知识与题目版本由服务器固定。引用只能使用检索得到的案例版本与原文位置；程序核验ID、结构、引用、目标与数学表达式，模型内容单独标识待人工核对。

- 新API只接受教师自己创建的任务；跨用户/角色返回明确拒绝，服务端构造上下文。任务去重、失败降级、无案例、材料未就绪、格式错误、取消、刷新离开和重启均纳入验收。
