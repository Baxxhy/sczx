# 教师学情统计口径

2026-11-11，v1。

原独立检查汇总直接累加正确尝试，确有重复计数问题。现在后端insights.metrics统一按学生ID、任务ID和发布题号分组；同一学生对同题先错、再对、再次对：尝试3次、已答1题、独立正确最多1题、独立正确学生最多1人。任务ID隔离不同发布版本，不能按当前课程编辑内容重算旧任务。

| 指标 | 口径 / 分母 |
| --- | --- |
| 作答尝试 | 原Attempt稳定ID去重后的次数 |
| 已答题目 | 学生×任务×发布题号的唯一组合；包含随堂练习 |
| 独立检查题目 | 上述组合最近一次未获得帮助，且题型为check/replacement；未核验另列 |
| 独立正确题目 | 最近一次独立检查且程序核验正确；人工意见不算程序正确 |
| 独立正确学生 | 当前范围内至少有上述一题的学生去重人数 |
| 问题正确/错误/未核验人数 | 每道发布题每名学生最近作答；同刻矛盾记未核验 |
| 有帮助学生 | 对该题有实际帮助后作答记录的不同学生，保留重试过程 |
| 有独立正确/错误证据学生 | 知识点内曾有对应可核验独立事实的学生；可同时具有两类历史证据，区别于最近结果 |
| 待错题复测/已复测 | 依据原错题及关联dynamic_v1独立新题结果，旧固定示例不算 |
| 需要补强/证据不足 | 复用第十四步规则状态，非能力诊断 |

教师首页learningMetrics、班级报告和任务summary.metrics复用同一后端投影；单个StudentRecord.metrics也复用同一统计函数。首页原stats契约保留，防止破坏已有调用。学习记忆的independentCorrect为原始独立正确事件次数，与唯一题目数不同，页面及接口不把两者混称。

班级概览只计算本教师、当前班级的在班成员；跨班学生在各班各计一次，各班任务不串。移出记录不参与当前人数，但可从既有单任务历史只读回看。班级人数、已分配人数、实际作答人数、已核验人数分别返回，不互作分母；页面不输出混合百分比。

参与/提交/逾期显示所选任务当前状态；日期过滤作答、帮助和知识证据，tooltip明确差别。日期按北京时间当日零点至次日零点转换为UTC闭开区间；带时区时间按实际时区转换。无法确认的历史时间不参与区间统计，数量单列。旧数据库生成作答以历史+08:00为基准，SCZX_FACT_TIME_OFFSET_SECONDS默认28800；SQL读取会话换成UTC不会改变旧证据时间。程序生成的反馈及审计保持UTC。更换部署写入时区前必须核对历史来源，不能根据读取连接静默重解释历史。

帮助、未知核验、旧固定补救和人工确认单独保留。程序不将模型自称正确当作验证；同刻相互矛盾的结果不按随机ID选成功。
