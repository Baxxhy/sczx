本轮基线为 sczx/main `746a2a1947a037ab6da1c30600570e85cc494a19`。用户新增要求优先：所有页面从功能堆叠改成任务工作区；继续 Vue 3＋JavaScript，不引入 React、TypeScript 或第二套状态/图标/动画库。

## 设计决策

用户需要先看见当前对象和下一步操作。统一采用 Nova 黑白灰，Lucide 图标、Motion 轻量过渡、shadcn-vue/Reka 组件；保留现有 Splitter、VueDraggable 和 Pinia。依赖清单没有增加。

- 入口：学生 5 个、教师 6 个常驻导航，其余进入“更多功能”，全站搜索可以定位真实页面与当前账号的任务。
- 首页：当前任务、任务列表、消息反馈分主次，不再使用占据首屏的装饰性课程插画。
- 阅读：课时正文优先，目录与学习助手切换；没有阅读块的补充任务使用直接练习路径。
- 编辑：一次处理一个对象；编辑/预览/版本分开，保留保存、预览、发布的明确位置。
- 工具：筛选、历史、来源、额外配置按需展开，错误与影响当前决定的条件仍直接显示。
- 列表：使用共同列与行对齐，不给每行重复解释；短列表保持真实数量，不填充虚构内容。
- 文案：删除重复说明、口号、技术ID与装饰性次要标签；保留教学正文、表单标签、文件限制、错误恢复、不可逆操作后果。

已安装 RedSkill CLI 0.1.0，并通过 `redskill install un-design` 安装 un-design 1.0.0。实际读取的入口为 `skills/un-design/un-design/SKILL.md`；另安装到本机 Codex 技能目录。安装来源与摘要保留于 `skills/.redskill-lock.json`。规则用于逐页信息分组，不以删字数量作为验收。

frontend-design、design-taste-frontend 的 app-screen 规则用于中性色、层级与截图自审。参考 [shadcn工作台](https://ui.shadcn.com/blocks)、[Linear](https://linear.app/features)、[Notion](https://www.notion.com/product) 的任务组织思路。Awwwards/Webby/FWA 作为审图方向，不将内部评分或自动检查包装为实际获奖认证。

## 已发现与修复

1. 页面首次渲染同时展示全部功能。改为明确的列表、编辑、预览与历史视图，保留业务能力。
2. 部分旧色值带紫色或文本太浅。统一中性色，检查实际背景上的对比度；状态仍使用必要的语义色。
3. 键盘跳至正文链接会改变 hash 路由。改为保持路由并聚焦 main。
4. 首页已提交页签为空时显示“暂无分配”。改为对应当前页签的空状态。
5. 教师考试详情没有对应导航及面包屑。关联组卷与考试入口。
6. 只有题目的补充任务进入阅读页后显示0/0与空目录。加入直接练习视图和正确首页入口。
7. 学习页重复课时标题。学生阅读使用页面h1，预览仍有独立标题。
8. AI教案的教师执行文字进入学生页面。采用显式学生标题/正文；旧AI任务从其自身冻结课时版本投影，历史快照不改写。新实例通过原有修订/审核/发布接口发布五个新版本。
