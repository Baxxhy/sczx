# 初高中全学科通用化实施计划

目标：将一元一次方程演示改为可录入、发布和学习初高中各科内容的通用平台。保留既有课时、任务快照、原始作答和上传；现有数学课程仅作为一组示例。支持全科内容，不将其表述为已经内置所有年级、所有教材。

采用writing-plans组织工作、executing-plans推进实现。前端保持Vue 3＋JavaScript及Element Plus，业务后端保持FastAPI与MySQL。

1. 建立共享学段、年级、学科、题型和核对模式，支持自定义学科；落地分科提示词与一元一次方程专项附加提示词。
2. 解除课程及题库对方程的强制要求。客观题按配置核对，数学表达式仅在支持范围程序核对，主观题保留原答、评分依据并交由教师评价。
3. 课程管理、课程浏览和错题录入加入学段学科与题型；创建课时继承课程元数据，不再自动变为七年级数学。
4. 学生作答支持选择、多选、判断及文字作答；方程工具、天平和专门数学文案仅用于适合的内容。
5. 教师备课、AI候选题、OCR、指导和错题补救携带实际学科年级；通用补救不要求生成方程，主观变式不伪装成程序判对。
6. 修正跨学科作答、错题来源、学情及历史版本关联；保留原数学核验与既有数据兼容。
7. 完成跨学科单元及隔离MySQL业务验收、浏览器操作、实际提示词调用、构建与文档，验收后按约定提交并推送。

验收重点：语文/英语主观题无需方程即可发布和保存；客观题选项准确核对；非一元一次数学题可人工评阅；多科课程与任务不串用年级学科；所有常见学科有可调用提示词，未知学科回退通用指导。未准备的教材不以空壳课程或虚假发布记录填充。

进度：七项工程任务及跨学科实际调用、三端浏览器操作已完成；检查结果与范围见[交付与验收](初高中全学科通用化交付与验收_20261112_v1.md)。
