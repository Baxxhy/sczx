# 核心创新对照实验方案

日期：2026-11-14。第三轮待执行方案，不是已完成实验或教学效果结论。

## 要回答的问题

比较三种方案是否改变实际指导内容、策略适切性、来源引用和独立复测表现。第一轮的规则测试、真实Codex单次指导不能作为C优于A/B的证据。

|方案|输入与处理|
|---|---|
|A 普通模型|当前题目、当前学生提问和公开学科信息，不给案例或学习记忆|
|B 检索增强|A的内容＋同一冻结语料检索的候选案例，不加入本轮可信/困难匹配决策或学习记忆规则|
|C 匹配与记忆|B的同一检索器与候选预算＋来源筛选、学习困难证据、适用范围检查、真实或明确模拟的学习记忆|

三组使用同一提供者、模型版本、low思考强度、输出结构、时限、最大修复次数与答案泄露检查。C额外规则与来源门槛必须公开，防止把语料差异误当算法增益。

## 冻结样本与来源

- 先收集16个情境：语言类4（语文/英语）、数理类4（数学）、自然科学4（物理/化学/生物）、人文社会4（历史/地理/道德与法治）。代表性不等于所有19科均已有效。
- 每个情境包含题目、原始答案与说明、困难证据、允许的前置知识、可用经验和许可、预期需要确认的地方、独立新题及评分要点。
- 在16个情境中覆盖同一问题不同历史、帮助后正确、开放题未核验、无可靠经验、错误来源与边界不满足、失败重试等情况。
- 优先经同意且去标识的真实材料；不足时明确标为“团队自编模拟情境”。专家尚未招募，不预填姓名或教师身份，不把AI起草当专家标注。
- 独立题在生成前冻结，不能为某组量身编答案，也不能让评分者看到组别。
- 第一轮工程夹具不是本实验的已冻结评测集；原第八步小样本标签不能直接冒充全学科标签。

## 执行控制

冻结语料、CaseVersion、提示词文件哈希、模型返回版本、CLI版本、思考强度、题目及标签版本。当前CLI不提供受控随机种子/temperature接口时记录“不支持”，不编造参数。每情境每方案运行3次，初始预算16×3×3＝144次；修复重试单列，不选择性删除失败输出。

对同一情境交错运行A/B/C，尽可能降低调用时段影响。保存输入、原始结果、验证失败、修复次数、选用来源、最终状态及耗时。超时、限流、无合适经验和拒绝结果都计入分母。

## 指标与评分

|指标|记录与判断|
|---|---|
|困难识别|专家事先定义可支持的观察和原因范围；无足够依据时正确保留不确定，不奖励武断诊断|
|策略适切性|盲评0不适用/1部分适用/2可执行且对应当前困难；附原话与理由|
|来源真实性、引用正确|逐条检查来源类别、许可依据、版本ID、原文定位及引用内容是否支持论点；不存在/错归类单列|
|教学内容正确|按实际学科评价要点评阅，数学工具仅核对其支持范围；严重错误单独统计|
|不同学生的差异|成对比较相同题目不同已知历史，变化是否有事实依据；不得只靠措辞不同得分|
|独立复测|冻结新题、区分独立/帮助；无真实学生时只能报告模拟情境推演或结构正确性，不能报告学习增益|
|教师可用性|真实教师完成找教法/改教案任务的成功率、时间、修改量与访谈；第一轮没有这些受试数据|
|成本与响应|所有尝试的耗时分布、调用及修复次数；计费或token不可取得时记缺失，不估写成本为0|

至少两名有相应学科能力的评阅者独立评分，记录分歧及协商；若只能获得一人，明确降为单人评阅并保留原分。不用模型自评替代教学适切性评阅。

## 汇总与失败分析

公开每情境原输出与全部失败，不只给平均分。小样本先报告分布、逐例差异与不确定性，不据16情境推断全学科或乡村学生整体提升。C若因边界过严漏召回、引用了经验却未采纳教法、或记忆触发错误策略，列为失败并定位规则；修复后用新版本重跑相关全部组，保留旧结果。

实验开始前完成样本、许可与人工评分规则确认；第一轮只交付此方案，不发生144次调用或专家评阅费用。
