# 跨课时记忆与复习推荐

2026-11-10，v1。

指导仍使用原有tutoring/ModelJob/Codex gpt-6-luna/low。读取本人有权限的结构化事实，按当前知识点和一层前置关系选择最多6条其他任务证据，优先独立错误/复测、已确认错因、教师核对或反馈。每条含稳定来源、时间、知识点、核验/帮助状态、关联原因和不超过180字摘要；关联修订另保留纠正ID。

不读取并发送全部历史聊天、不重复发送旧图，不引入新模型服务或向量库。最终输入仍受既有24000字符预算约束；无相关记忆正常使用当前课时。历史证据不能压过学生本轮实际回答，也不能据一次错误形成长期能力标签。真实跨课时指导任务的输入与输出见本步browser-flow.json。

推荐为确定性规则，首页读取和刷新不调用模型。每个知识点至多一条稳定ID建议：review:studentId:knowledgeId。

1. 有原始错题且无该题独立复测通过：继续补救；已有新版练习后进入独立新题。
2. 有帮助后正确、缺独立证据：进入真实未作答检查题。
3. 当前知识的一层前置有两次独立错误，且无后续改善：提供前置课时入口与原证据。
4. 有可靠时间且到复习间隔：再次检查。
5. 暂无/不足证据：查看实际例题或补充练习。没有真实可用新题时不伪造题目链接。

教师可明确指定实际课时或错题，作为有人工依据的优先建议。仅打开页面不会完成建议；目标产生新的真实可核验作答后不再强制重复该条教师建议，原指示保留审计。错误后状态如何变化仍由真实事实计算。

学生可稍后处理，默认1天；记录的是偏好而不是“不愿学习”。稍后状态与当时证据摘要关联，新事实或相关依据变化后重新计算，避免混合历史时间口径造成错误隐藏。

目标只从本人已分配且仍可写的任务、本人个人错题或有效课程错题选择。被移出班级的历史允许回看，不推荐继续写入。任务检查入口选择真实未作答题号；补救入口复用第十三步，不清除原帮助记录。

从后续课时进入复习时携带returnTask/returnKnowledge，完成后既能回到学习记忆核对新证据，也能返回进入复习前的课时。原错题的“返回原任务”独立保留，不与后续课时混淆。

模型任务保留提交时的记忆快照以便审计；后续新提问重新提取最新事实，历史输出不被重写。
