# 第三步实施与验收

日期 2026-11-07　版本 v1

用户授权采用 grill-me 推荐方案。首课为等式性质，一个演示班级，一名可操作学生。教师选择案例、编辑并发布，学生学习和提交，教师反馈，学生读取反馈构成完整验收流程。

发布保存教案快照，后续编辑为草稿，再次发布创建新任务。浏览器内身份切换共享班级和任务，作答按任务保存。固定示例学生与操作记录分别标注。记录自动保存，重置需要后果确认。

1. 建立浏览器业务服务、版本化数据及旧记录迁移。实体包含案例、教案、发布任务、学生记录、作答、帮助、错题、补救和反馈，各记录具有关联ID与时间。
2. 按页面拆分已有大组件，建立明确路由与缺失记录反馈，统一异步加载、保存和错误重试。
3. 打通教师案例与教案、发布快照与班级任务、学生学习与检查、错题回流、教师学情与反馈。保留既有视觉体系，补齐空白和失败状态。
4. 管理草稿、发布案例、反馈与失败任务持久保存，提供开发用可重复失败触发及确认重置。
5. 浏览器验收完整流程、发布隔离、跨任务保存、刷新恢复、旧数据迁移、图片恢复、错误重试、无效路由、键盘和三尺寸。运行生产构建，修复问题，记录结果并提交。

第三步使用本地演示业务服务，后续以同一业务方法接入 Python API 与 MySQL。现有原图和旧浏览器存储保留。

上述五项已实现并完成浏览器验收。结果见《第三步使用与实现说明》，界面截图见视觉设计 v5。
