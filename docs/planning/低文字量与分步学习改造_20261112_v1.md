# 低文字量与分步学习改造

2026-11-12 · v33 · Vue 3＋JavaScript 本地 Web

用户指出上一版学习页仍像长文档，整课目标、七节正文、目录和助手同时竞争注意力。本轮继续使用已安装的 un-design，改变一次处理的信息量。

## 当前界面

- 学习、独立练习、错题订正使用专注工作区，左侧全站导航改为顶部“导航”入口。
- 学习页一次只显示一节。目标放入信息按钮，目录与助手按需打开；上一步/下一步就在当前内容底部。
- 公式独立排版，变量使用数学字体；例题按原始句子展示运算链。没有公式的概念节可引用同课已有例题，绝不从独立检查题提取答案。
- 练习一次只显示一道题。新题恢复自己的输入与是否用过帮助；旧反馈注明“上次作答”，不把旧正确结果贴在新空白输入旁。
- 错题按找错因、订正、再练推进，原题、原答、分类、历史均可回看；订正一次呈现一条。
- 复习页用“还需练习”“独立答对次数”等学生表达；离线阅读一次一节。
- 教师备课、AI建议一次处理当前活动，批阅一次一道题，保存成功才进入下一题；失败保留输入。
- 管理端材料阅读与整理分流，课程设置、问题轨迹和模型历史不再与正文同时展开。

必要字段名称、错误原因、不可逆操作后果和数学条件仍保留。正文和历史任务快照不改写，未新增依赖，未改后端或数据库结构。
