# 第七步使用与实现说明

日期 2026-11-09　版本 v1

本步完成桌面Web的课程、单元、知识前置关系、课时内容编辑与版本发布，首课为项目自编“等式性质”。教师选用发布课时后备课并发布班级任务，学生按任务快照学习、练习和提交。技术继续使用Vue 3＋JavaScript、FastAPI和MySQL；模型路线不变，本步没有新增模型请求路径。

## 启动与升级

沿用第四至六步的独立MySQL、环境变量、文件目录和CLI配置。在已有Python虚拟环境中安装当前业务包，停止API后执行：

```bash
cd backend-business
.venv/bin/pip install -e .
.venv/bin/python -m sczx_business.commands migrate
.venv/bin/python -m sczx_business.commands seed
.venv/bin/python -m uvicorn sczx_business.main:app --host 127.0.0.1 --port 8000
```

虚拟环境放在其他位置时使用对应可执行路径。MySQL必须先运行。新增迁移为`0007_curriculum`；初始化补充缺失的首课草稿、单元和知识点，不覆盖已编辑内容，不自动审核或发布课时。

项目根目录运行：

```bash
npm --prefix frontend ci
npm --prefix frontend run dev
```

浏览器默认访问`http://localhost:5177`。Vite端口以终端实际输出为准；API默认8000。构建命令为`npm --prefix frontend run build`。继续使用独立管理员、教师和学生账号，账号配置沿用已有说明，不在文档记录口令。

## 管理员：课程内容

进入“课程内容”（`#/content`），与“内容工作台”的资料案例管理分开。

- 左侧选择课程，添加单元和课时。课程目录可编辑名称、年级、学科和顺序；单元有独立顺序；课时可上移下移。课程、单元与课时分别保存独立ID。
- 中间编辑课时标题、学习时长、目标及内容块；右侧使用真实学生渲染组件预览。分栏可拖动，也可聚焦分隔条后按方向键调整。
- 内容块支持讲解、例题、天平、随堂练习和独立检查。可增删、拖动、用上下按钮或手柄方向键排序。块ID不随排序变化。
- 教师提示与学生正文分别保存。可上传插图、填写图片说明并移除引用；原文件不物理删除。读取失败显示重试。
- 题目页编辑用途、题干、单解方程、参考答案、提示和参考解释。内容块勾选关联题目；替换新题保留在本任务题目快照中，依次使用，不无限循环旧题。
- “知识与出处”设置本课知识点、前置知识、内容来源及参考案例。发布固定案例版本，材料原文可沿案例入口读取。
- “知识前置关系”维护全局知识点及前置ID；服务端拒绝重复边、缺失节点和循环依赖。已有知识点保留以免历史引用丢失。
- 保存草稿后进行内容核对；服务端检查必需字段、块与题目ID、题目关联、天平条件、知识点、案例和所列方程答案。核对后才可发布；任何内容修改都需要重新核对。
- 未发布草稿不进入师生课程目录。发布形成不可变版本；再次编辑需“创建修订”。停用后停止新选用和新任务发布，已有任务及历史版本继续保留。

数学程序核对仅覆盖所列单解方程与参考答案，不证明讲解全文或教学效果。当前不支持任意题型自动判定、多个解的方程、复杂试卷和模型生成代码。

## 首课内容

“等式性质”首课草稿含8个内容块：相等关系引入、正量天平、同加同减、加法例题、随堂练习、乘除条件、乘除例题、独立检查。首课包含2道随堂题、2道独立检查和2道替换新题。

天平只模拟非负实物量；负数关系通过公式表达。正文说明同除以非零数、不能除以零，以及两边同乘0虽仍相等但可能丢失原方程信息。题目包含加减、乘除与负数运算，学生解释保留供教师判断，不由数值正确推定解释充分。

内容属于项目自编教学示例，关联既有案例时保留其真实来源状态，不冒充教材摘录、名师审核或真实师生试用结果。其他单元课时仍为目录草稿；“自编验收”课程、课时与班级记录用于区分验收操作。

## 教师：选课、备课和发布

从“课程与课时”（`#/courses`）选择课时进入备课，或通过`#/prepare?lesson=课时ID`打开。

每名教师按课时分别保存教案。已有旧教案不会自动被新课时覆盖；点击“使用发布课时”，确认替换目标、活动、题目及来源，保留学生基础和截止日期。没有记录课时版本的旧教案需先选用发布内容，再发布新任务；历史任务仍可读取。

教师可修改目标、活动、顺序和题目，学生预览随修改更新；“恢复原稿”仅恢复该活动对应的发布原文。发布时选择班级、填写日期，并保存所选课时版本、案例版本、活动与问题快照。课时停用会阻止新发布。

管理员修订课时后，已有教师草稿与任务继续保留旧内容。教师主动选用新发布版本后，新任务使用新内容。预览中的天平、解释和作答只属于本地预览状态，不产生真实成绩或帮助记录。

## 学生：学习、检查和结果

学生目录只显示已发布课时。可预览内容；存在匹配本课的班级任务时进入该任务，没有任务时明确显示“尚无本课任务”。本步不创建自主学习实例。

学习页按任务快照渲染，右侧目录可定位内容块。阅读后标记完成；天平需实际增加数量并填写解释。解释、天平位置、逐题草稿和进度都按当前任务保存，可刷新继续。随堂与检查块的完成情况由实际提交的题目记录计算。

独立检查显示本任务题目；请求提示记录帮助后再显示提示。新题重新开始独立尝试；没有更多新题时显示耗尽状态。参考答案、教师提示和未请求的题目提示不随学生平台响应提前下发。

“提交本课结果”要求完成必需内容块、随堂题及必需检查题。提交表示流程完成，独立正确单独统计；无法解析的答案、图片或文字解释不能直接判为正确。服务端保存题目稳定ID及兼容下标；教师可查看原答案、解释、帮助、新题与补救记录，并保存反馈供学生回看。

## 数据与接口

新增`course_units`、`knowledge_points`、`lesson_contents`、`lesson_versions`；课程新增展示元数据，课时关联单元，教师教案增加`lesson_snapshot`。旧课时ID、任务和作答外键保持。

|接口|用途|
|---|---|
|GET/POST /api/curriculum/courses|课程目录、新建课程|
|PUT /api/curriculum/courses/{id}|课程名称、年级、学科及顺序|
|POST /api/curriculum/units；PUT /api/curriculum/units/{id}|单元创建与目录修改|
|POST /api/curriculum/lessons|在单元内创建课时草稿|
|GET/PUT /api/curriculum/lessons/{id}|详情、草稿保存、课时排序|
|POST /api/curriculum/lessons/{id}/{action}|verify、review、publish、revise、withdraw|
|GET /api/curriculum/lessons/{id}?versionId=...|读取指定历史发布版本|
|GET/PUT /api/curriculum/knowledge|知识点及有向前置关系|
|POST /api/curriculum/tasks/{task}/questions/{index}/hint|保存帮助记录并返回提示|
|GET /api/platform?lessonId=...|读取选中课时及对应教师草稿|
|POST /api/tasks/publish|明确携带lessonId及发布版本的任务发布|

课时版本保留内容快照，学生问题只投影可见字段。旧记录不重新判分，缺失历史版本不伪造。保存失败保留输入，可再次保存；切换课程/课时会提示未保存修改，直接打开与刷新通过课程/课时ID恢复。

后续阶段继续完整单元内容、Agent编排、完整题库、错题补救扩展和真实师生试用。本步只建设桌面Web，未开展移动端。
