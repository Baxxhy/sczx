# 桌面布局密度与留白调整

日期：2026-11-12。范围：师承智学本地网页，Vue 3＋JavaScript。沿用现有 Nova、shadcn-vue/Reka、Lucide、蓝色主题，不新增依赖。

## 参考与落地

参考 [Canvas课程仪表盘](https://community.instructure.com/en/kb/articles/662815-how-do-i-view-my-courses-in-the-card-view-dashboard)、[Moodle Dashboard](https://docs.moodle.org/500/en/Dashboard)、[shadcn Dashboard](https://ui.shadcn.com/blocks/dashboard)。取用任务与辅助区分栏、课程列表、侧栏导航等组织方式；shadcn 的 React 示例只作布局参考，实现使用项目既有 Vue 组件。

使用 information-architect 整理班级和课时入口；design-taste-frontend 检查实际数据密度与主操作；verification-before-completion 核对构建、浏览器操作和完成声明。

## 修改与复查

| 问题 | 本轮处理 | 验收 |
| --- | --- | --- |
| 桌面内容宽度受限，大屏两侧空白 | 工作区随可用宽度展开，正文局部保留行长限制 | 1440、1920、2560 三种宽度检查 |
| 班级卡片横跨整行，仍要跳转找任务 | 左侧选择班级，右侧直接显示该班真实任务 | qmx选班、刷新、进入任务通过 |
| 学习页短内容拉满，目录藏在弹窗 | 桌面常驻课时目录，右侧当前步骤；窄屏保留弹窗目录 | 实际鼠标点击目录，当前内容切换通过 |
| 练习页窄居中，左右空置 | 桌面左题目、右作答，下一题贴近表单 | 页面检查、原有作答回归通过 |
| 订正页单列窄居中 | 桌面原题与订正步骤分栏 | 既有订正浏览器回归通过 |
| 首页摘要、列表及编辑器间距过大 | 收紧摘要、列表、课程行、账号行，移除备课编辑区宽度上限 | 首页、课程、教师备课、管理端截图复查 |
| 历史消息标题仍带中点 | 仅显示时替换，不改数据库原文 | 保持既有主题与元信息规则 |

首轮截图发现只扩展学习卡片宽度仍不够，随后加入常驻课时目录并重新执行浏览器回归和三端尺寸检查。

## 验证结果

- `npm --prefix frontend test`：40/40，通过；包含任务、目录、作答、订正等现有回归。
- `npm --prefix frontend run test:unit`：12/12，通过。
- `.venv/bin/python deploy/build_frontend.py`：构建通过，记录构建输入；仍有既有大包体积提示。
- 实际账号三端26个页面，三种宽度，共78次页面检查：无横向溢出、无页面错误提示；浏览器未捕获脚本异常。该检查是页面与布局检查，不等同于重新验收全部业务操作。
- 本地8099更新通过；qmx登录、选择班级、刷新、任务按钮、鼠标点击课时目录通过。
- 未修改业务模型、数据库结构或上传文件；本轮未重新执行后端算法与全量MySQL测试。
