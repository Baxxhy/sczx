# 第十一步使用与实现说明

日期 2026-11-10　版本 v1

本步在既有Vue3/JavaScript、FastAPI、MySQL和LearningTask/StudentRecord上补齐班级、任务分配与业务消息。没有另建一套学生任务，也没有新增模型、队列或聊天室依赖。

## 使用

教师打开“班级教学”，新建或编辑班级名称、年级、学科。可添加已有学生，或生成1/7/30天有效的邀请码供学生在“我的班级”输入；邀请码仅生成时展示，可撤销。无效邀请码10分钟内尝试5次后暂缓重试。成员列表显示同一教师名下的跨班归属。

切换班级后只显示该班任务，地址中的class保留选择，刷新可恢复。由当前班级进入备课会带入发布班级。发布采用原教案和课时快照，支持无截止日期；创建学生记录与新任务消息在同一事务中完成。教师任务状态来自全部已分配记录的汇总，学生状态来自本人记录。

晚加入学生不会自动获得旧任务。教师点击对应历史任务的“补发给当前成员”，仅为尚未分配的在班学生创建原任务学习记录和消息，重复操作不重复创建，也不复制或修改快照。成员移出前有明确提示：保留原作答、解释、原图、求助和反馈，本人历史仅可回看，不能新增学习作答；再次加入恢复原来已分配记录，从未分配的任务仍需补发。

教师在学情页的“补充与订正”新增说明、订正要求或补充学习，可选全部已分配在班学生或指定学生。说明只能阅读；订正和补充学习可开始、提交说明并接受后续反馈，不会把原课自动标成完成或宣称数学正确。无人开始时可取消，已开始后需另发说明，原记录保留。旧版补充文本仍是说明，不自动转换为待完成作业。

学生首页显示本人待办、学习中、已提交、班级及持久消息；教师首页按当前班级显示任务数、未提交学生人数、待反馈记录和最近提交。首页未提交人数按在班学生去重；任务汇总的已分配、已提交和未提交统计保留历史分配记录，移出人数另列，便于回看。学生“待完成”不包含已移出的只读记录。

铃铛可查看全部消息；教师可切换收到的消息和发送记录。消息包含新任务、截止、逾期、教师反馈、订正和补充学习，关联班级、任务、发送人与收件人。读后、刷新和重新登录保留状态，点击可进入相应任务；私人补充及反馈只返回给对应学生。

## 截止与提醒

日期型截止按北京时间当日23:59:59.999999判断；空日期表示无截止。显式时区时间转换成UTC，无时区时间按北京时间解释；到截止点仍未超过，之后未提交才逾期，已提交不再转逾期。新任务时间、消息时间和安排时间由服务端写入UTC，前端按Asia/Shanghai显示。

截止前24小时和逾期提醒在平台、首页或消息HTTP读取时计算并写入MySQL，稳定事件键去重，重复读取不重发。当前阶段没有后台定时推送；所有人都不访问时不会主动唤醒浏览器。

## 数据与接口

迁移0010在classrooms增加subject，在supplemental_instructions增加kind/due_date/status，新建class_invites、class_join_throttles、business_messages、supplement_recipients。原任务、作答和上传表不重建。邀请码保存哈希；消息按业务事件唯一键去重，补发使用原task_id/student_id唯一关系。前端重试同次补充安排沿用requestKey。

|方法与路径（均以/api开头）|用途|
|---|---|
|GET /teaching/classes|本人可访问班级|
|PUT /teaching/classes/{id}|教师编辑班级|
|GET/POST /classrooms/{id}/members|教师查询/添加成员，重复添加保持幂等|
|DELETE /teaching/classes/{id}/members/{student}|移出，保留学习历史|
|POST/GET /teaching/classes/{id}/invites|生成/查询邀请|
|POST /teaching/classes/{id}/invites/{invite}/revoke|撤销邀请|
|POST /teaching/join|学生加入班级|
|GET /teaching/classes/{id}/tasks|当前班级任务与汇总|
|GET /teaching/tasks/{id}|授权任务详情与本人状态|
|POST /teaching/tasks/{id}/assign|原任务补发，studentIds数组|
|GET /teaching/dashboard?classId=…|真实首页统计|
|GET /teaching/messages?box=inbox或sent|本人收件/发送记录|
|POST /teaching/messages/{id}/read|本人消息已读，幂等|
|GET/POST /teaching/tasks/{id}/supplements|读取/创建安排|
|POST /teaching/supplements/{id}/start或submit|开始/提交说明|
|POST /teaching/supplements/{id}/cancel|教师取消未开始安排|
|PUT /teaching/supplements/{id}/students/{student}/feedback|反馈已提交说明|

发布、作答、提示、原图与反馈继续走原接口。业务写入检查在班成员身份；教师原班级所有权、学生已分配记录及安排收件范围共同决定可读写内容。旧异步班级响应不能覆盖新班级，离开首页后的旧响应也不能触发导航。

## 运行和验证

保留现有MySQL与模型配置，先在backend-business执行`python -m sczx_business.commands migrate`，再运行`python -m uvicorn sczx_business.main:app --host 0.0.0.0 --port 8000`。前端`npm --prefix frontend run dev`，本机入口5177。

隔离验收种子入口为backend-business/tests/seed_teaching_acceptance.py，仅接受sczx_test_*库，不能用于覆盖真实账号。完整命令及截图见[证据索引](../verification/teaching_20261110_v1/README.md)。
