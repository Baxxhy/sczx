# 师承智学系统代码迭代步骤

日期 2026-11-07　版本 v1

1. **梳理现有代码与功能入口。** 对照 v9，逐项核对现有账号、题图上传、OCR、诊断、辅导、练习、复习、知识卡、学习任务、学习记忆、组卷、导出和管理功能，确认实际可运行程度以及需要复用、改造和补齐的部分。

2. **确定完整平台的模块划分。** 将师承智学划分为学生学习、教师教学、教学内容管理和平台公共服务，将错题帮设置为学生端可单独进入的子软件，并确定它与课程学习、练习、复习和教师反馈的连接方式。

3. **整理前后端工程结构。** 在现有 Vue 网页、Python/FastAPI 业务后端和 Python 算法服务基础上，按账号、课程、教学案例、班级、教学任务、学习过程、错题帮和内容管理整理代码模块及接口归属。

4. **建立平台数据升级能力。** 完善 MySQL 增量迁移，支持已有数据库升级与新环境初始化，保留现有账号、学生原图、题目、作答和学习记录，并将历史记录关联到新的平台模块。

5. **补齐完整教学流程的数据结构。** 增加资料来源、教学案例及版本、课程单元、课时、教案、班级成员、教师发布任务、学生任务实例和反馈记录，打通它们与现有知识点、题目、学习事件和复习记录的关联。

6. **完成统一账号与角色入口。** 复用现有注册登录和个人资料，补齐学生、教师、项目管理人员的身份与工作入口，支持教师任教信息、学生年级和班级归属，以及对应的页面与业务操作。

7. **建设统一网页应用框架。** 完成 Vue Router、TypeScript、Pinia、Reka UI 和 Tailwind CSS 的整合，建立平台导航、三端布局、公共组件、接口类型和状态处理，并衔接现有页面入口。

8. **完成核心页面的新界面。** 按师承智学设计统一学生首页、学习工作区、错题帮、教师案例页、备课页、班级任务页、任务反馈页和内容管理页，完成电脑、平板与手机上的布局适配。

9. **统一业务接口与后台任务机制。** 整理现有接口及任务执行逻辑，补齐平台各模块的创建、编辑、保存、查询和提交能力，统一任务进度、失败重试、重复提交处理、SSE 消息和中断恢复。

10. **统一外部模型 API 适配。** 保留 ApiPoolProvider，统一文本、图文/OCR、Embedding、Rerank、ASR 和 TTS 的调用入口、配置和结果格式，将现有本地模型入口迁移到外部 API，完成 CPU 服务运行所需的依赖调整。

11. **建立公开资料管理功能。** 完成资料登记、上传、解析、原文查看和版本管理，记录作者、出处、使用条件、学段、学科与知识点，支持管理人员整理和修订公开教学材料。

12. **完成教学经验提炼流程。** 利用文档处理、图文 API 和结构化模型输出，从公开材料中提炼教学目标、适用基础、常见困难、讲解步骤、提问方式与调整策略，将提炼结果关联到对应原文位置。

13. **完成教学案例编辑与发布。** 提供可读案例的编辑、预览、核对、发布、修订和停用功能，接入 Pydantic、SymPy 及项目成员核对，保存案例版本及其被课程、教案和学习过程使用的记录。

14. **建立课程、单元和课时管理。** 支持配置学习目标、前置知识、讲解内容、活动、例题、随堂练习和独立检查题，将现有知识卡与知识关系接入课程结构，并关联适用教学案例。

15. **完成首课内容与演示数据。** 沿用 v9 暂定的一元一次方程单元和等式性质首课，录入完整课时、优秀教学案例、教案素材、互动活动与练习，建立明确标注的演示班级和演示学习记录。

16. **建设教学经验与课程检索索引。** 在现有题目检索基础上增加教学案例和课程材料检索，接通 Embedding API、BM25、Qdrant 和 Rerank API，支持按学科、年级、目标、困难和内容版本筛选，以及发布后的索引更新。

17. **完成 Agentic RAG 检索流程。** 支持根据备课需求或学生困难组织查询、补充检索条件、查找相关案例、读取原文上下文和整理可引用结果，在材料不足时继续查找或明确反馈缺口。

18. **扩展现有 Agent 与 LangGraph 编排。** 将已有辅导、规划和学习流程扩展到教师备课及课程教学，形成规划、经验检索、教学组织、练习生成和结果核验的协作流程，接入结构化工具调用、运行记录与检查点。

19. **完成目标级学习记忆。** 复用现有学习记忆、掌握状态和知识关系，统一记录课程进度、原作答、使用过的提示、独立完成情况、错题原因和待复习目标，为后续指导提供连续上下文。

20. **完成教师教学案例工作区。** 支持教师搜索和筛选案例、查看原文及适用条件、收藏案例、选择备课素材，并查看已有教案中使用过的案例。

21. **完成教师辅助备课。** 支持教师填写教学目标、课时安排和学生基础，结合优秀案例生成可编辑教案，修改讲解、提问、活动、例题和练习，保存草稿、版本并预览学生学习内容。

22. **完成班级管理。** 支持教师创建班级、邀请学生、管理成员和查看学生基本学习情况，支持学生加入班级并在学习首页查看班级与教师信息。

23. **完成教学任务发布。** 支持教师将教案中的课时、活动和练习发布给班级，设置完成时间、查看参与与提交状态，并为每名学生建立学习任务，保留发布时的内容版本。

24. **完成学生学习首页。** 汇总教师任务、自主课程、继续学习、待复习内容和错题帮入口，让学生能够从教师安排、自主选择或历史学习进度进入对应流程。

25. **完成课程学习工作区。** 支持学生按课时阅读讲解、查看例题、完成活动和随堂作答，保存每一步进度，并与教师发布任务、自主学习记录和知识目标关联。

26. **完成经验驱动的互动指导。** 将现有对话辅导接入课程与案例检索，支持文字提问、上传题图、分步提示、举例、换讲法、补基础和自己尝试，根据学生回应调整指导并保存使用过的帮助。

27. **完成首课互动教具。** 在现有 VisualizationSpec 与可视化组件基础上实现等式天平，支持操作、观察、解释和提交活动结果，将互动记录接入学习过程及教师反馈。

28. **完成练习、批阅与独立检查。** 复用现有出题、作答、手写上传和批阅能力，接通随堂练习、变式练习和独立新题，支持反馈、订正、再次尝试，并分别记录作答表现与帮助使用情况。

29. **完成错题帮子软件整合。** 将现有采集、裁剪、OCR 修订、手动录题、错因诊断、辅导、变式和检索页面接入平台统一界面，支持课程练习错题转入错题帮，以及补救后返回原学习任务。

30. **打通复习和持续学习。** 复用现有复习计划、知识补救和掌握状态，将课程学习、独立练习与错题订正产生的待复习目标统一安排，支持查看原题、历史作答、补充讲解和复习后的变化。

31. **完善保存、暂停与继续。** 贯通页面草稿、作答保存、文件上传、后台任务和 Agent 检查点，完成刷新、退出重进、网络中断与服务重启后的进度恢复，让学生和教师能够继续未完成的工作。

32. **完成教师作答与学情反馈页。** 汇总班级任务完成情况、学生原作答、共同困难、提示使用和独立完成结果，支持查看个人学习过程，并确认或修改系统生成的反馈。

33. **完成教师针对性指导。** 支持教师根据学情查找相关教学案例，为班级或指定学生安排补充讲解、订正、练习和复习，记录案例使用意见，并查看后续任务完成情况。

34. **完成反馈处理与内容改进。** 支持学生和教师反馈讲解错误、内容不理解及使用问题，管理人员可定位关联案例、课时和学习记录，处理反馈、修订内容并跟踪处理结果。

35. **完善项目管理工作区。** 汇总待核对材料、待发布案例、课程内容、用户反馈、失败任务和服务状态，提供内容处理、任务重试、账号管理、运行记录查询与数据备份恢复入口。

36. **打通首课全部使用流程。** 使用隔离数据库实际走通资料整理、案例发布、教师备课、班级任务发布、学生学习、互动指导、独立练习、错题补救和教师反馈，核对每个页面、接口和持久化结果并修复问题。

37. **核对现有功能迁入后的行为。** 逐项检查原有题图、OCR、诊断、辅导、练习、复习、知识卡、检索、组卷和导出入口，确认历史数据可读取、已有操作可完成、跨模块跳转正确，并处理迁移产生的回归问题。

38. **完成教学链路运行评测。** 通过实际操作和运行记录检查案例检索是否匹配教学目标、引用是否对应原文、数学核验是否正确、指导是否响应学生困难、教师是否能追查反馈依据，修复失败任务和恢复异常。

39. **扩展到完整教学单元。** 沿用首课流程补齐一元一次方程单元的其他课时、教学案例、前置知识、练习和单元检查，完成跨课时进度、连续学习记忆、单元复习与教师单元反馈。

40. **完成首版部署与实际使用。** 部署 Vue 网页、FastAPI 业务服务、算法服务、MySQL 和 Qdrant，配置外部模型 API、文件存储、服务启动与备份恢复，实际完成新用户登录、建班、发布任务和学生学习，交付可持续访问的首版平台。

41. **根据使用记录完善首版。** 收集项目成员实际操作记录，在具备条件后补充真实教师与学生试用，改进页面、教学案例、备课结果、学习指导、任务耗时和错误恢复，记录真实使用效果。

42. **扩展语音与互动教具。** 在统一 API 适配基础上完成语音提问、识别结果编辑、讲解朗读和播放控制，增加与后续课时匹配的互动教具，将语音与操作记录接入原有学习流程。

43. **扩展组卷、考试与批量导出。** 复用现有组卷和 PDF、Excel 导出能力，增加教师选题、试卷编辑、班级考试发布、考试作答、批阅、讲评以及教案、试卷和学习记录的批量导出。

44. **扩展详细成长记录与分层教学。** 在已有知识关系和学习事件上增加跨课时、跨单元成长展示，支持教师查看不同知识目标的变化、调整系统建议的学生分组，并发布对应层次的学习任务。

45. **扩展课堂实时互动。** 增加教师课堂会话、活动推送、即时答题、课堂结果汇总和课后任务衔接，将实时课堂记录与既有班级、教案、学生学习记录及反馈统一关联。

46. **扩展教师教研交流。** 增加教学案例与教案分享、讨论、收藏、改编和使用反馈，支持将实践中形成的经验整理为新案例，继续进入内容核对与发布流程。

47. **扩展完整离线学习。** 增加课时和材料下载、本地学习与作答保存、离线进度记录、联网后的任务同步及冲突处理，明确各学习活动对网络与模型 API 的依赖，并完成断网到恢复联网的完整使用检查。

48. **按使用需要扩展工具对接和课程覆盖。** 为已有教学、检索和内容能力补充 MCP 工具适配，沿用课程与案例管理流程扩展更多单元、年级和学科，检查新增内容与既有学习记忆、教具和批阅能力的适配情况。

49. **完成扩展功能的全平台联调与发布。** 将语音、考试、成长记录、分层教学、实时课堂、教研交流和离线学习接入三端统一导航与数据流程，完成多班级使用、服务重启、数据升级和备份恢复检查，修复问题后发布完整版本。

50. **完成最终交付与持续运行准备。** 更新安装部署和三端使用说明，整理内容维护方式、模型 API 配置方法和版本升级步骤，提供明确标注的演示数据与演示视频，使用新环境从安装到师生完成完整单元走查一遍，并持续跟进实际使用反馈。
