# 状态提醒与视觉层次调整

2026-11-12。本轮处理三端状态颜色、反馈提醒及工作区视觉层次，沿用 Vue 3＋JavaScript、shadcn-vue/Reka、Lucide、现有 Motion 交互，不新增依赖。

## 统一规则

| 语义 | 示例 | 颜色 | 图形 |
| --- | --- | --- | --- |
| 待处理 | 待完成、待审核、需人工核对 | 琥珀 | 时钟 |
| 进行中 | 学习中、考试中、正在生成 | 蓝 | 播放圆环 |
| 已完成 | 已提交、已完成、已保存 | 绿 | 对勾 |
| 异常 | 保存失败、核验不一致、逾期 | 红 | 警示圆环 |
| 信息 | 获得帮助、需要提示 | 青蓝 | 信息 |
| 普通或不可操作 | 草稿、历史、已取消、未配置 | 灰蓝 | 保留文字 |

蓝色仍是品牌及主操作色，其他颜色只表达状态。所有标签保留文字，图标只辅助辨识。没有修改学习记录、教师反馈或核验结论；“需核对”“证据不足”不会因为调用方传入绿色而显示为完成。

`status-tone.js`集中解析现有状态文字及兼容旧tone字段；未知文字保持中性或调用方既有语义，不生成新的业务判断。`Status.vue`渲染同一套颜色与图标，动态切换文字时同步更新。若后续业务增加新状态，应补充该模块或显式传入语义。

成功/失败浮层分别使用对应色，保留读屏播报。OCR不确定项、复核提醒为琥珀色；原任务只读提示为中性色；生成进度为蓝色。失败与重试保持原有操作。

考试列表原先将“进行中 / 待开始”混写，现根据开始、结束及成绩发布字段在页面渲染时给出单一状态，不更改考试时间或提交规则。

## 视觉调整

- 工作区使用浅冷色底，白色卡片与细边框形成层次。
- 首页当前任务使用浅蓝区域，统计按待处理、进行、完成分色。
- 任务图标、正文标题、链接和悬停状态统一蓝色语言。
- 课程头部、当前题号、步骤进度、订正当前步骤保持统一选中反馈。
- 沿用已有Motion按钮与减少动态效果偏好，不引入闪烁、循环装饰或新增说明段落。

使用ui-ux-pro-max检查状态、反馈和对比度；design-taste-frontend用于桌面卡片及截图自审。
