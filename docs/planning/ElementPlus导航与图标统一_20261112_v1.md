# Element Plus 导航与图标统一

2026-11-12。按用户要求，移除文字左侧的装饰竖线，导航与图标继续统一到 Element Plus。

## 本轮变化

- 三端侧栏使用 ElMenu / ElMenuItem，删除原选中项的 inset 3px 阴影条。
- 顶部分类使用 ElTabs / ElTabPane，保留可直接打开的路由链接与上下文参数。
- 头像使用 ElAvatar。
- 全项目73种业务图标别名统一对应 Element Plus Icons，通过 ElIcon 使用官方SVG及尺寸接口；卸载 Lucide，不再混用图标库。
- 同步去掉案例引用和订正引用中的粗左边装饰线；保留面板之间的结构分隔。
- 保留业务内容、数学图示、原始上传和已有反馈数据。数学教学图形不作为通用图标替换。

采用[官方Menu组件结构](https://element-plus.org/en-US/component/menu.html)与[官方Icon用法](https://element-plus.org/en-US/component/icon.html)，沿用项目自己的业务页面组织。
