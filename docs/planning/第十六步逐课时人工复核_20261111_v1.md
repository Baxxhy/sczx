## 等式性质

目标：理解等式两边共同变化的条件，能用同加、同减、同乘和同除以非零数求未知数，并解释每一步。

### 相等的两边

等式表示两边的值相等，例如5 = 5。只改变一边通常不能保持相等。先预测两边同时增加相同数量后会怎样。

### 让天平两边一起变化

天平两边各有5单位。两边同时增加相同的正量，观察结果，再用自己的话解释。此实物类比只展示非负数量。

### 同加、同减

若a = b，那么a + c = b + c，a - c = b - c。c可以为正数、负数或零。关键是两边同时进行相同运算。

### 例题：消去减去的数

x - 3 = 5
两边同时加3：x - 3 + 3 = 5 + 3
得到x = 8。把8代回，8 - 3 = 5，成立。

### 随堂练习

每一步都说明两边进行了什么运算。

### 同乘、同除的条件

若a = b，则ac = bc。若c ≠ 0，则a / c = b / c。除数不能为零。
等式两边同乘0虽仍相等，却可能丢失原方程的信息：x = 2乘0得到0 = 0，不能从0 = 0恢复x = 2。解方程时可逆变形必须保留条件。

### 例题：共同除以非零数

3z = 18，两边同时除以3：z = 6。
w / 4 = 3，两边同时乘4：w = 12。
负数也可参与运算：若b / (-3) = 2，则b = -6；用公式表达，不把负重量放到天平上。

## 解简单的一元一次方程

目标：用等式性质解加减、乘除及两步方程，并代回原式验算。

### 确定未知量与运算顺序

一元一次方程含一个未知数，未知数最高次数为1。先看未知项外面做了什么运算，再逆向逐步消去；每一步两边必须同时进行相同运算。

### 系数与非零条件

解4x=20时，两边同除以4，4不为0。解x/(-3)=4时，两边同乘-3。除数不能为0；为保持方程等价，解题时同乘的数也取非零数。

### 代回原式

把候选值代入原方程，分别计算左右两边。两边相等才与原式相符；计算相符不替代对推理过程的解释。

### 例题：先加减后乘除

解2x+3=11：两边减3得2x=8；两边除以非零数2得x=4。验算2×4+3=11。

### 例题：负数系数

解-2x+5=13：两边减5得-2x=8；两边除以-2得x=-4。验算-2×(-4)+5=13。

## 含括号与分母的方程

目标：用分配律、合并同类项及同乘非零公倍数解方程，解释移项并验算。

### 移项来自共同运算

从2x+3=11到2x=11-3，实际是两边同时减3。移项后的符号变化来自共同运算，不能只移动一个符号而不检查等式。

### 去括号与合并同类项

用分配律展开每一项：-2(x+3)=-2x-6。括号前是负数时，两项都要乘这个负数；合并时只合并同类项。

### 去分母的范围

本课分母均为已知非零常数。两边同乘这些分母的非零公倍数时，左右两边的每一项都要乘。含未知数分母的题还需定义域和增根核对，本课不作自动评分。

### 例题：括号与两边运算

解2(x-3)+4=10：展开得2x-6+4=10，即2x-2=10；两边加2再除以2，x=6。验算2(6-3)+4=10。

### 例题：常数分母

解x/2+x/3=5：两边同乘非零数6，得3x+2x=30；5x=30，x=6。原式6/2+6/3=5。

## 一元一次方程单元复习

目标：联系等式性质、方程变形和实际数量关系，独立求解并用原式与情境验算。

### 选择解题路径

先辨认结构：加减、乘除、括号或常数分母。每一步写明依据。需要前置知识时回看对应课时，不把记住“移项变号”替代等式运算。

### 核对条件与结论

同除的数必须非零。两边同乘0仍相等，但会丢失方程信息，不能用来求原方程的唯一解。0x=0有无穷多解，0x=1无解；本单元自动评分只覆盖可验证的单变量唯一实数解。

## 条件专项预期

1. 同加/同减任意相同数保持相等。
2. 同乘相同数保持等式；同乘0会丢失方程信息，不能当等价求解。
3. 同除的数必须非零；不得除以0。
4. 移项来自两边共同加减，去括号对每项应用分配律。
5. 本单元分母为非零常数，去分母时每一项同乘非零公倍数。
6. 负数和分数系数允许参与运算，代回原方程验算。
7. 应用题须说明设元、单位、数量关系和正数/整数等情境条件。
8. 无解、多解、含变量分母和文字条件无法可靠核验时，不自动判对。
