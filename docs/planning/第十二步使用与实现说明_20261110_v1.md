# 第十二步使用与实现说明

日期2026-11-10，版本v1。第十二步完成；第十三步未启动。

## 学生使用

在课程学习页阅读、操作既有天平和作答，目录保留当前块及进度。点击题目旁“向学习助手提问”会关联该题并聚焦输入区。独立检查换题或切换任务时读取该记录自己的草稿，刷新继续上次题号、输入和指导。

学习助手支持给我提示、举个例子、换种讲法、补基础。先选择方式，再输入问题或对追问的回答；“回答后继续指导”结合实际回应和最近相关轮次继续，不主动无限运行。换讲法需改变表达方式，补基础只用当前知识点的一层前置关系，不根据一次错误断言学生未掌握。

“我想自己试试”保存程序检查点，不调用模型，也不清除之前的求助。点击返回原题后，答案与解释仍在原作答区提交。原题获得帮助后不能变成独立完成；另一道新题重新按该题的求助记录判断。

题图先上传保存原图，再识别。核对文字和数学表达式后才获取指导；本轮以确认的题图为指导对象，原任务题目ID仅保留业务关联。不同图片的对话不能混用。识别失败可重试或改用文字，改用文字会清除待重试图片指针，原图及失败历史仍保留。

顶部结束按钮可以停止本轮，已保存历史保留；开始新一轮会重置对话父节点和旧图上下文。失败后可手动重试原输入。离开网页不取消已排队任务；服务中断的任务保留输入、结果及失败状态，可重新进入后手动重试。

## 教师使用

在学情页查看学生实际问题、指导方式、识别、确认文字、原图、后续回应、求助和独立作答，再沿用原反馈入口保存意见。学生重新进入结果页可读取反馈。教师自己的案例、备课、导出和班级操作不另建一套。

移出成员后，历史可读；创建、重试、执行前和写回前都检查当前在班权限。排队任务不再启动有效指导，运行中的结果不写入学生指导；任务和请求记录不删除。真实运行中移出及手动重试403已实测。

## 边界与接口

使用现有ModelJob/ModelRun/ModelEvent/HelpRecord/StudentRecord及MySQL JSON，无新增表、迁移或依赖。前端继续Vue3/JavaScript、Nova、Reka、Lucide及既有Motion。

|接口|本轮行为|
|---|---|
|POST /api/ai/jobs|学生text统一进入受控指导；guidance字段不是可绕过规则的开关|
|GET /api/ai/jobs?recordId=…|本人或有权限教师读取过程；返回策略、块、父轮、实际问题|
|GET /api/ai/jobs/{id}|读取输入、结果、执行与成本；私有核验答案不返回|
|POST /api/ai/jobs/{id}/retry|本人失败任务重试，重新检查在班权限|
|POST /api/ai/jobs/{id}/stop|结束自己的指导并保留历史|
|GET /api/ai/jobs/{id}/events|复用既有SSE/轮询，终态包含cancelled|

text的data可包含prompt、strategy（hint/example/rephrase/foundation/try/continue）、question索引、blockId、parentJobId；题图再包含ocrJobId、confirmed、recognizedText、confirmedEquation。服务器从实际任务、课时快照、公开案例和知识关系重建context，忽略伪造历史、答案和上下文。

输入上限：问题3000字，核对文字6000字，公式500字；超长明确拒绝，避免静默改写原始输入。模型默认最多最近4轮，单次教学输入最多24000字符。过长来源只在模型输入中节选；数据库原文、引文及已发布快照保留。每次明确操作最多一次主要生成、一次结构/质量修订；交互任务不再自动连续重试。CLI单请求115秒，业务任务150秒，失败留待手动处理。

原问题、学生回应和当前策略存在job.input；父轮用parentJobId关联。scope保存studentId、classId、taskId、lessonId、lessonVersionId、questionId和knowledgeIds。案例及版本冻结在本轮input，实际使用来源在result.sources；不能把仅检索到的来源冒充已引用。原图用file_id关联，OCR原文和确认文字分开保留。请求幂等键和请求指纹保证响应丢失后重放不会新建第二条求助。

程序核对声明关系和可解析数值等式，拦截已核验的不一致、直接原题答案、照抄原题的举例及无依据断言。未知内容显示需核对；结构合规和单条等式正确都不代表全文教学正确。

## 运行

沿用已有MySQL与Codex登录配置，无新迁移。从backend-business运行`python -m uvicorn sczx_business.main:app --host 0.0.0.0 --port 8000`；前端`npm --prefix frontend run dev`，入口5177。已保留原配置重启本地主服务，原业务数据摘要未变。隔离验收入口及命令见[证据索引](../verification/tutoring_20261110_v1/README.md)。
