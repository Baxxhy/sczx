# 真实账号注册与学号入班

2026-11-13 / v1

已将注册、登录和教师按学号加学生接入现有FastAPI与MySQL，不使用浏览器演示身份。沿用已有班级、任务、成员关系和会话，无数据库结构变更。

## 使用

1. 打开登录页，选择“注册”。学生填写姓名、学号和密码；教师选择教师身份，填写姓名、账号和密码。注册成功直接进入自己的工作区。
2. 学生的学号就是登录账号，在本软件内唯一，至少两位、不含空格；教师账号与学生学号共用唯一账号空间。密码至少六位，已有账号仍可直接登录。
3. 教师进入“班级教学”，新建班级，填写名称、年级、学科。
4. 在“成员与邀请”输入已注册学生的学号，点添加。学生随后打开班级页即可看到该班；重复添加不会产生重复成员。
5. 也可生成邀请码，让学生在自己的班级页输入邀请码加入。已发布的旧任务按现有“补发历史任务”操作分配；之后发布的新任务按当前成员分配。
6. 注册的账号、密码哈希、班级和成员关系均保存在MySQL，退出、刷新和重新登录保留。教师不能注册为管理员，学生不能创建班级。

本轮学号采用登录账号，不额外引入学校范围、同校重复学号和教务编号体系。教师尚不能代未注册的学生创建账户；学生可自主注册，管理员仍可创建账号。
