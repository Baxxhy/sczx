# 教学干预与实际作答

2026-11-11，v1。

继续使用SupplementalInstruction、SupplementRecipient、StudentRecord和BusinessMessage。没有第二套任务系统。新增details保存知识点、各学生真实目标、发布时原始事件/题目基线，以及选中的CaseVersion快照。

教师从学情选择知识点，查看原答后，可按全班已分配在班成员、指定学生或有独立错误证据的候选安排。候选只依据实际可核验独立错误，不把暂无/证据不足状态直接当困难；候选模式默认一个也不勾，必须手选、预览名单并确认发布。后端再次核查班级、分配和错误依据。

支持补充讲解、错题订正、前置知识复习、独立复测及教师说明。目标可为本班该学生实际已分配的课时，或本任务中该学生的原错题；不允许分享个人独立错题或其他学生错题。前置复习由教师选择真实前置课时，知识关系可在已有记忆页核对。可设截止日期。

从共性问题进入既有BM25案例检索，携带知识、问题、年级、学科和返回来源。阅读案例后“用于补充教学”返回学情；安排中显示案例名称，发布保存当前版本及来源，不自动发布模型建议。案例后来修订不影响旧安排。

发布在原事务写入安排、收件关系和消息；同一请求键重放不重复发送，内容变化复用旧键则409。学生打开、提交说明沿用原流程；进入安排内容继续真实学习或错题补救。

效果按发布时基线与目标过滤新Attempt/RepairAttempt，不以打开/提交说明作为通过。重复做原题可有新尝试，但不能冒充独立新题。只有此前未作答的新题、未帮助且程序核验正确，才显示“新增独立正确证据”；原帮助、原错误和教师审计保留。学生完成不等于因果上的教学有效。

未开始安排可取消；已开始后保留历史，另发说明。移出成员不能继续写任务或安排，历史仍可按原权限回看。
