# 第十三步使用与实现

2026-11-10，v1。师承智学桌面 Web，Vue3/JavaScript + FastAPI/MySQL；无新增依赖。

学生登录后直接打开侧栏“错题帮”，查看自己的课程错题和个人错题。可搜索并按学科、知识点、错因、补救状态筛选。点击“录入错题”可以仅填文字，也可上传图片；拖出矩形或输入选区百分比，另存裁剪图，再识别、修订题干和数学表达式，核对后保存。多道题图片需选择并确认一道；原图永远另存保留。

打开详情后，先看原作答，点击“分析错因”。模型给出可能错因、原始证据、订正目标、步骤和检查问题；学生可以修改分类并确认。填写“你的理解”继续本题指导，或按需要提示、举例、换讲法、补基础。未使用助手时四个入口收在工作区顶部，产生指导后展开原题/订正/助手三栏。

“生成变式练习”得到经程序核验的实际新题；填写答案与过程后提交。“生成独立新题”重新检查，不沿用原答案或清除历史帮助。结果记录实际题目、作答、是否帮助与核验状态，课程来源有“返回原任务”；个人错题回个人列表。

教师在原任务学情详情查看错因、指导、实际变式、独立新题与作答。无法程序核验的作答可人工确认；人工意见单独保存，保留原程序状态。个人错题不会自动共享给班级教师。

浏览器刷新可恢复本题草稿、任务状态及补救历史；录题中的已上传文件/OCR标识保存在当前账号的会话草稿。网络保存失败会保留输入，恢复网络后“重试保存”；OCR或模型失败保留输入和运行记录，可手动重试。已移出班级的课程来源历史仅可回看。

运行沿用 README：后端安装已有依赖，执行迁移，启动8000；前端 `npm --prefix frontend run dev`，正常入口 http://localhost:5177。当前本机服务已加载0011，隔离验收使用8013/5183，与正式数据分开。

实现入口：remediation.py、grading.py、visualization.py；前端 wrongs.js、WrongQuestions.vue、WrongCapture.vue、Repair.vue、BalanceActivity.vue。文字指导仍复用 tutoring.py 和 ModelJob，OCR仍复用现有上传/模型队列。

已完成工程验收与三条真实业务流程；模型自然语言不作全数学正确保证，符号核验范围与具体限制见评分设计和未解决问题。证据入口：../verification/remediation_20261110_v1/README.md。
