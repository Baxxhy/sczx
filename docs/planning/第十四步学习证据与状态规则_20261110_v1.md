# 学习证据与知识点状态

2026-11-10，v1。

证据由原表惰性聚合，不复制一套原始学习记录。来源为Attempt、HelpRecord、WrongQuestion、RepairAttempt、教师核对与反馈；保留原始事件ID、题目、原答、解释、帮助标志、核验状态、任务/班级/课时版本及时间。eventId以来源类型和原始ID构成，evidenceId追加知识点；同事件关联多个知识点时各点独立归类，首页总数按事件去重。辅助帮助/错因元数据不增加有效作答次数。

原始关联来自发布任务的问题或课时快照，以及个人错题中的已保存知识点；关联缺失单独显示，不冒充已知知识点。教师关联纠正通过追加记录叠加，原题、原答、数学核验和发布快照不变，原关联可追查。

| 状态 | 可解释规则 |
| --- | --- |
| 暂无证据 | 没有相关记录 |
| 证据不足 | 单次正确/错误、仅帮助成功、未核验、仅人工意见或旧固定示例均不足以输出掌握结论 |
| 需要补强 | 最近两条独立可核验作答都错 |
| 正在改善 | 旧错误后出现新的独立正确事实，但尚未达到不同题的充分独立成功条件 |
| 已有独立正确证据 | 至少2道不同题独立正确，最近独立事实为正确，且错误后有足够的后续成功 |
| 需要再次复习 | 有可靠时间的独立成功事实距今达到复习间隔 |

同一时刻出现相互矛盾的正确/错误时，不凭随机ID推断先后，显示证据不足。接受帮助的练习与独立新题分开；历史固定z+2=9不计入新版独立成功。教师数学核对单列，不伪装程序验证。教师要求复核也单独显示，不能等同于能力诊断。

默认阈值：独立不同题至少2，近期窗口48小时，复习间隔7天，稍后处理1天。环境变量依次为SCZX_MEMORY_MIN_INDEPENDENT、SCZX_MEMORY_RECENT_HOURS、SCZX_MEMORY_REVIEW_DAYS、SCZX_MEMORY_SNOOZE_DAYS；使用有边界的正整数配置。近期窗口用于近期事实统计，不作遗忘衰减。规则可测试、可重算，未经过真实教育实验校准。

数据库现场NOW与UTC_TIMESTAMP相差8小时。原字段不改写：数据库生成的事实时间按实际会话时区换算为UTC，教师反馈/新审计记录使用程序UTC。保留rawOccurredAt与timeBasis；历史演示导入无法确认时间口径时标记不可靠，不据此自动推断复习间隔，页面显示“时间待核对”。迁移部署若更改数据库时区，应先核对旧数据时间口径。

状态与推荐在读取时按最新结构化事实重算，无额外模型调用、无全量历史模型文本扫描、无状态缓存表。revision包括原事实、审计、配置及派生状态；新作答、复测、教师核对、关联修订或时间阈值变化都会反映到新结果。状态变化时间线是按当前规则与各时点已有事实回算，不冒充历史系统曾给出的诊断。
