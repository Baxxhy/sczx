# 学生困难识别与教学策略匹配设计

日期：2026-11-14。第一轮采用透明的保守规则，不新增AI Agent、画像存储或检索服务。

## 一次指导的数据流

`tutoring.prepare`按当前账号、StudentRecord、LearningTask快照重新读取题目、课时、知识点、最新Attempt及原有learning_memory.related_memory。忽略客户端伪造的context/history/参考答案。原答案仍只保存在原作答；用于指导的题目公开字段不含参考答案。

在既有ModelJob.input.context中保存：

- difficultyAssessment：学科维度、观察事实及ID、历史事实、证据充分性、待确认问题、recommendedStrategy和理由。
- experienceDecision：选用案例ID/版本、实际教法、证据ID、困难匹配词、来源声明、不适用原因及fallback。

同一记录提交重放仍返回第一次任务；历史判断保留当时快照，不随案例新版改变。最终结果也带这两个对象，便于回看。长原文裁剪后，仍可引用实际发送的选中教法版本；不会允许输入之外的版本。独立尝试不选用新教法、不调用模型。

## 困难与策略规则

|情况|行为|
|---|---|
|只有一次错误、学生自述，或开放题未评阅|记录原话/答案与待确认问题，possibleCauses为空，不下认知病因结论|
|相关历史中至少两条已核验且未获帮助的独立错误/复测失败|continue默认先补基础；理由明确引用重复困难事实|
|帮助后作答、未核验作答|不计入上述触发条件|
|用户明确选择提示、举例、换讲法、补基础或独立尝试|保留选择；本轮不越权替用户改变已明确的操作|
|继续对话请求不理解|保留原有补基础逻辑；“明白了/自己试”进入独立尝试，不写掌握结论|
|要求换种表达或举例|保留对应策略及representation、原题泄露检查|
|题图已修订确认但知识点未核实|用确认文字和自述作为当前证据，不继承原练习答案、知识判断或学习记忆；本轮经验匹配退化|

19学科的diagnosticDimensions在`prompts/subjects.json`配置。语文、数学、物理、历史等维度不同；自定义学科使用通用任务/依据/应用维度。维度只是观察框架，不是自动诊断标签。

## 经验匹配

1. 复用原BM25、知识关系和情境检索，候选数量沿用现有上限。
2. 要求已知学科、年级和知识关联符合；缺标注也不能假定符合。
3. 候选须具有审核者且审核来源快照与当前来源一致。
4. unknown与ai_candidate不进入可信候选；许可须明确且有依据；具体教法或可执行步骤非空。
5. 学生当前自述/说明与案例difficulty或diagnosis字段至少有实际词项交集。保存matchedDifficultyTerms；交集是词法相关证据，不是已证明存在该认知困难。
6. 任意非空自由文本boundary须人工确认，本轮不假装能自动解释并证明任意条件；不符、待确认和拒绝原因保存。
7. 最多选三条，通过当前明确策略使用其method。无合格候选回退通用AI指导，并显示来源未匹配提示。
8. 模型收到选用教法、诊断事实、来源类别和效果检查。程序约束usedCaseVersionIds只能来自实际输入；有选用候选时至少引用其中一个版本，否则按原修复/失败机制处理。

教师备课复用同一策略，结合教学任务描述与当前课时，从检索候选及已选参考中筛选。教案里旧的人工引用仍保留，不把未审核旧案例自动变成可信经验。

## 已知限制及下一轮

- 未做同义表达模型推断；没有词项交集会保守退化，可能漏召回。
- 适用边界需要后续明确的人工作用域确认；本轮非空边界不自动选用。
- 引用了正确版本不等于语义上完整采纳教法；真实模型输出仍需人工查看，不能仅用ID证明教学效果。
- 未核验的开放题必须等待教师评阅，不通过数学规则冒充已判对错。
- 学习记忆本轮影响建议策略，不改变历史分数、掌握状态或原教师反馈。尚未进行策略间因果效果归因。
