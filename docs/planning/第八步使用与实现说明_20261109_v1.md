# 第八步使用与实现说明

日期 2026-11-09　版本 v1

本步在现有 Vue 3＋JavaScript、FastAPI＋MySQL 工程中完成教学情境检索。默认使用字段加权 BM25、已确认知识关联和课时上下文；教师可主动选择 Codex 重排。模型仍为 gpt-6-luna / low。没有新增向量服务、模型部署或运行依赖。

## 运行与入口

先按第四步说明配置 backend-business/.env、MySQL 和现有 Codex 登录目录。在 backend-business 目录使用已安装项目依赖的 Python 环境运行：

```bash
python -m sczx_business.commands migrate
python -m uvicorn sczx_business.main:app --host 127.0.0.1 --port 8000
```

前端在项目根目录运行：

```bash
npm --prefix frontend run dev
npm --prefix frontend run build
```

开发入口为 http://localhost:5177/；使用原有独立管理员、教师和学生账号。已有数据库只执行增量迁移，不通过重建或清空数据库升级。

## 管理案例和知识

1. 在“课程内容 → 知识前置关系”维护名称、每行一个的别名和前置知识。保存后检索读取新配置；名称或别名冲突、重复 ID、循环前置关系会被拒绝。
2. 在“资料与案例”选中案例。已发布案例先“创建修订”，进入“知识关联”搜索和勾选知识点；待确认建议不会自动写入。
3. 保存、对照原文核对并发布。新版本保存 knowledgeIds 及发布时名称；旧版本和已发任务不改写。

用户已批准 C、D 两篇自编案例关联“等式性质”；A、B 继续无关联。历史关联建议与标签见[人工复核记录](第八步小样本人工复核_20261109_v1.md)。

## 教师检索和备课

在“教学案例”输入目标、学生困难或想寻找的讲法。年级、学科和知识点按明确选择生效；默认可包含一层前置，取消后只使用目标知识。未知年级不会自动算作七年级。教学情境影响字段权重，课时信息只作辅助。

结果呈现已有教学目标、困难、方法、来源与版本。“为什么匹配”展开实际匹配字段、词和知识关系。分值不表示概率或教学正确率。阅读案例后可定位原文，并“用于备课”；发布任务校验实际选中案例的版本。

“Codex重排”仅处理已有候选，失败保留原排序并提示。查询、筛选和任务 ID 写入地址栏，刷新可恢复；切换条件后旧响应不能覆盖当前结果。重排期间案例修订或撤回时，实时结果排除过时版本并提示重新检索，历史任务结果仍可追溯。

## 学生指导与教师回看

从班级任务进入学习或独立检查。学生问题结合当前任务快照、题干、算式、知识点、目标和已有解释检索；“为什么要这样做”等简短提问也使用当前题上下文。完全无关问题不因年级相同而强行召回。

上传题图后先核对文字，再“确认题目并获取提示”。确认文本、原图、当时检索来源和版本随指导保存。先展示提示，分步讲解按需展开。教师在学情“查看过程”中读取同一份来源及原文位置。

同一版本同时属于课时来源和情境检索时合并一份，保留两种来源身份及匹配依据。参考材料表示提供给模型的依据，不声称模型实际逐条采用了所有材料。请求帮助后本题记录获得帮助，新题另行记录独立尝试。

## 实现边界

- POST /api/ai/search 接受 query、filters、context、includePrerequisites、limit；拒绝客户端传入正式语料。GET /api/ai/search 保留旧入口，空查询浏览有效发布案例。
- GET /api/ai/search-options 提供实际筛选项。重排走现有 /api/ai/jobs 和 SSE；学生指导复用同一个纯检索函数，不额外调用重排模型。
- 默认召回最多20、展示8、学生参考3。教师详情与历史指导使用固定版本，实时浏览使用当前发布集合。
- 请求原文与规范化结果分开；NFKC、名称/别名、中文二元组和数学符号规则集中在 retrieval.py。知识边只扩展一层，输出解释来源于实际字段和关系。
- 学生完整提问及确认文字仍保存在指导输入中；检索字段按请求契约限长，避免长文本造成服务端校验异常。
- 0008 仅增加可空 aliases 列。回退优先停服务并运行上一版代码、保留新列；确需删列时先备份别名，仅将0008回退到0007，不删除案例或任务。隔离库已验证往返迁移。

当前只验收桌面 Web。错题补救仍使用界面明确标注的固定变式练习，任意题型补救留后续步骤。真实教师语料、教学效果和跨学科泛化尚未验证；本次小样本未证明可选重排有稳定增益，因此保持主动开启。
