# 第十三步完整业务验收

2026-11-10，v1。所有账号、课程、错题和图片均为隔离库内项目自编数据，不代表真实课堂效果。

流程一：教师在浏览器修改目标、保存教案并发布新任务；学生独立检查作答15（原题3z=18），形成保留Attempt来源的错题。学生分析错因、填写理解、继续指导，提交实际变式，再提交另一道独立新题；核验通过后返回原任务，教师打开学情读取真实记录。见 browser-flow.json 的 flow1 系列及 teacher-history-final 截图。

流程二：学生进入个人错题帮，上传包含两道题的原图，裁剪第一道，真实OCR，人工改为“解方程x-3=5”及对应数学表达式，填写原答2及原过程。原图和裁剪图分别保存，完成分析与实际变式后退出并重新登录，核对原题、过程、两张图和补救历史。见 flow2、final-output-audit.json 和 two-questions.png。该原图为程序绘制验收样例，未使用真实学生材料。

流程三：连续打开3x=18、x/4=3、2(x-1)=10三道不同困难的个人错题，分别读取各自分析和练习历史，再通过浏览器生成独立新题、输入实际答案/过程并提交，三个结果均为retest_passed，实际方程、参考值、答案与帮助标志分别保存在对应RepairAttempt。见 flow3-browser-actual-independent-answer。没有以只打开页面代替实际评分。

E01—E04覆盖加减、乘除、分式逆运算及括号；E05/E06覆盖除零和乘零信息问题，保留证据不足说明；E07使用OCR结果后人工修订负号表达式；E08同图两题经裁剪选择并确认；E09缺条件题被拦截自动出题/判对；E10独立个人录入无任务ID。实际模型任务和输出在 real-cases.json，程序模拟/注入故障另记 faults.json。

恢复与隔离：空个人列表、无搜索结果、无效详情、实际断网保存及恢复、刷新草稿、天平单侧/共同增减/重置与刷新、教师读取历史均在 states.json。跨学生、不同教师、个人题图不共享、移出班级只读和旧记录保护通过隔离MySQL测试。失败记录和原始输出不删除。
