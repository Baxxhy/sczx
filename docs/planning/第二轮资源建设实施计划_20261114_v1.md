# 第二轮资源建设实施计划

目标：建设直接可用的全学科经验资源；普通教师不承担上传、萃取或配置工作。保持现有库、账号及前端。

1. 核对远程main及19学科，在线核对国家、地方、高校、开放教育来源，分别记录可访问性、作者/机构、日期、许可和主题。仅有目录或不可读取正文不计可用经验。
2. 整理首批目标57条独立经验；依据可访问来源逐条编写动作、追问、调整、独立检查，标清原文内容与项目适配建议。资料不足记录缺口，不凑数。
3. 交付版本化资源数据及可重复执行导入脚本：稳定ID/指纹、事务、差异预览、人工审核凭据、默认不覆写已有数据/版本；测试库默认运行。
4. 接入现有知识关联、检索、经验策略、备课和学生辅导；检查适用边界、未经审核退化以及来源缺口，不新增经验库/萃取Agent。
5. 真实MySQL/API验证覆盖、去重、修订保护、八科指导/备课/独立复测及教师读取，实际模型与受控模型分别留证；真实浏览器检查教师找教法与学生求助的操作步骤和断网反馈。
6. 输出19科逐项验收表、来源与许可目录、未完成项及CI结果。人工内容审核是出版门槛，不把AI自动检查或沙箱审核夹具当成人工核验。
7. 提交并按项目子目录根树推送sczx main，核对树和GitHub CI。正式库历史不改，不安排公网部署。
