# DOCX与教学语言专项修复说明

日期 2026-11-10　版本 v1

本轮完成第十步的Word导出与后续生成语言专项修复。原版文件保留在exports/20261110_v1；新版在exports/20261110_v2。没有开始第十一步，没有覆盖教师草稿、已发布课时/任务、原材料或旧Agent记录。

## 原文件与修改

原样例82个段落，Letter纸张，正文微软雅黑11pt，标题继承主题字体/颜色，引用同文因字段标签不同重复输出。现有系统Office启动失败；本轮在环境中发现并复用已存在的独立LibreOffice 25.2.7.2以及SimSun、Times New Roman，没有修改系统Office配置。

|问题|修改位置与处理|实际结果|
|---|---|---|
|中西文字体混乱|docx_export.py对正文、全部样式及其条件样式、docDefaults、页眉页脚逐一配置ascii/hAnsi/cs=Times New Roman，eastAsia=宋体，清除主题字体|所有生成DOCX的XML检查通过；PDF实际中文字形SimSun，英文数字Times New Roman|
|标题主题色与蓝线|全部文字明确000000，清除主题色；移除模板继承的段落装饰边框/色块|渲染全部文本纯黑，无彩色装饰线|
|纸张/行距/层级|A4，上下2.5cm、左右2.7cm；正文12pt、1.35倍、段后4pt、首行24pt；标题18pt居中，一级14pt/二级12pt加粗；页脚居中PAGE域|逐页检查无乱码、越界或孤立标题；短题目的题干、答案、提示、讲解作为同页段组|
|正文连续堆叠|按基本信息、目标、学情、重点难点、教学过程、练习、检测、来源组织；缺失数据不编造|旧样例同版正式教案由5页变3页；完整溯源4页|
|来源重复|按材料/页面或单元/规范化同文去重，消除同一句因结构字段前缀重复；保留案例版本关联|正式版只放摘要/位置和短依据；溯源版附去重完整依据；原数据库引用未删|
|系统过程用语|lesson_plan新增教师语言规则、可执行短步骤、预设回应等字段；teaching_quality.py提示元话语、重复标题/句段、空泛活动及同除条件风险|三类真实新生成结果规则警告为0，用户认可表达风格|

独立文件docx_export.py仅负责导出呈现，drafts.py保留原接口和数据职责。没有新增运行依赖或数据表。

## 使用

在备课页或历史版本中点击导出，可选“正式教案”或“完整溯源版”。发现疑似编辑标记时会列出原句；清理选项默认关闭，选中后预览可处理前缀，明确导出后只作用于下载副本。数学内容、原引文和数据库原文保留。

用户已明确同意仅对本次样例清理“教师手写保留：”“保留例题：”“沿用例题”等前缀。因此新v12样例清理这些前缀，但保留原目标和教学长段落。旧教案的整体措辞没有被后台重新生成；新语言约束用于后续新生成建议。

Agent的新字段为studentTask、teacherQuestion、studentResponse、adjustment，均可编辑。采用前在差异窗口显示新旧内容；质量警告不删字，也不自动再调模型。教师可对一项生成任务主动要求一次质量修订，新的ModelJob用qualityRevisionOf追溯，后端拒绝第二次及修订链；原任务结果保留。普通局部生成沿用原流程并保持其他块。

## 实际渲染与Office

五份DOCX共19页：原正式3页、原溯源4页、三份新样例各4页。逐页截图、XML字体/颜色检查、PDF实际字体/颜色/边界检查均归档。渲染时数学减号可能由系统符号字体提供；中文及普通拉丁字母/数字的实际字体检查均正确。

通过独立LibreOffice的真实文档接口完成打开、插入临时段落、另存DOCX、关闭、重新打开和读取该段落；原文件哈希不变。用户随后明确确认“Word/WPS显示正常，编辑保存重开成功”。软件品牌及版本未由用户补充，不推断具体Word/WPS版本；本地实测版本为LibreOffice25.2.7.2。两类证据分开保存。
