# 第十九步离线数据、缓存与同步协议

2026-11-11，v1。

## 服务器包与数据结构

`GET /api/offline/tasks`只列出本人当前班级的普通已分配任务；`GET /api/offline/packages/{task}`生成schema=1白名单包，包含userId/taskId/lessonId、固定publishedVersionId和versionId、标题目标、公开blocks、question题干/公式/图引用、knowledgeIds、下载时间、72小时offlineUntil、内容摘要、服务器草稿摘要与本人必要草稿。blocks的教学正文属于已发布学生内容，互动隐藏配置、参考答案、评分规则、教师备注、其他学生和管理员数据不进入包。不保存完整/platform、会话Cookie/Token或模型凭据。

图片由当前身份逐项取回为数据URL，下载全部成功后再原子替换密文；失败不覆盖旧包。资源不放入公共Cache Storage。任务快照中图片的既有读取权限缺口已修复：只允许本人已分配任务或教师本人任务引用的文件；其他学生仍403。

MySQL新增0016_offline_drafts，父版本0015，只追加offline_operations表，主键(owner_id, operation_id)，保存请求摘要、成功回执、创建时间。复用StudentRecord.drafts，不新增第二套作答/成绩/画像。0015隔离库迁移前后51个旧表完整行摘要一致，新表初始为空；正式库未执行。downgrade拒绝删原始同步证据，回滚应恢复到独立备份库后另行批准切换。

## 本机存储与身份

IndexedDB sczx-offline-v1/vaults保存账号目录哈希定位的密文。PBKDF2-SHA256（210000次、随机盐）派生不可导出的AES-GCM-256密钥，随机96位IV，账号目录作为附加认证数据。owner、包、草稿和操作状态封在同一个认证密文中；本地独立口令和密钥只在当前解锁内存，刷新/重启重新解锁，不保存服务器明文密码。改userId不能解开或同步别人的记录。

同一浏览器在线B账号不能用A下载进入A内容，即使输入A的离线口令也拒绝；离线时仅允许凭正确本机口令打开原下载，联网每次同步都重新校验服务器身份。退出默认删除当前账号密文，明确保留时仅留密文；待注销布尔标记不含凭据，恢复网络后在其他API前处理。忘记口令不能恢复密文，需要清除后重新下载。

断网无法实时获知服务器之后的撤销，本机72小时策略不是持续在线鉴权；正式写入永远由服务器当前权限/时间决定。系统与浏览器本身已解锁的当前用户上下文不属于对恶意浏览器扩展的防护承诺。

## 精确同步协议

每个操作包含operationId、userId、taskId、questionId、versionId、baseRevision、modifiedAt、answer、reason、helped、position；额外字段拒绝。@position只写当前课时合法blockId。普通题仅写该固定版本的答案/过程，保留服务器已有帮助状态，不改Attempt、核验、完成、反馈、成绩。modifiedAt只作记录，不决定截止。

versionId为固定任务快照/题目摘要，包含原版本来源；不是“当前课程最新版本”。baseRevision为服务器drafts/observation规范JSON的SHA256，可检测原聚合或精确接口造成的修改，不需要改写历史行增加修订列。

POST /api/offline/sync依次核对当前账号、已有幂等回执、本人分配、班级成员、撤回/来源/提交/服务器截止、内容版本、草稿摘要。并发用账号/班级/记录锁；回执与帮助/成员证据采用MySQL加锁当前读，避免REPEATABLE READ旧快照误报冲突。同ID同内容返回同回执，不重复写入；同ID变更内容409。成功提交事务后才返回synced和新revision。普通在线记录保存也加锁，已提交/已撤回记录不会被聚合自动保存覆盖。

客户端先确认在线身份，再按保存顺序同步。一次成功后更新同任务后续本机操作的基线；冲突停止该任务后续自动覆盖，失败保留原输入。恢复中断的syncing状态可幂等重试。服务端409返回原因、原服务器草稿、serverRevision、allowRetry；仅可写的修订冲突允许用户对比确认后新operationId重试。版本变化/撤回/已提交/超时/移出班级只保留副本，不能绕过。

状态：等待同步（本地事务完成）、正在同步、已同步（收到服务端成功回执）、发生冲突（允许人工确认的CAS变化）、已失效不能提交（权限/内容/时间状态）、同步失败（可重试）。“已保存到本机”是持久化事实；不产生正式Attempt。学习位置和题目互不混淆。

## 应用外壳

Vite构建按产物清单生成sw.js；shell缓存名随哈希资源变更。安装预取index、JS、CSS、字体，激活删除本应用旧壳缓存。首页网络失败回退缓存index；清单资源缓存优先。GET /api及其他业务图片/请求全部绕过，不缓存认证响应。仅生产注册，不以开发服务器缓存代替验收。

独立/#/offline入口跳过在线会话和聚合保存门禁；不初始化整份旧平台数据。返回在线流程重新验证账号并重读最新状态，避免旧前端快照覆盖已同步内容。认证和平台读取带上下文代数，旧初始化、旧账号或旧课时请求不能覆盖新状态。
