# 第十七步功能与技术说明

2026-11-11，v1。用户已明确本项目沿用Vue3＋JavaScript、FastAPI与MySQL；AGENTS已记录这一覆盖旧仓颉/TypeScript背景的决定。**功能已在隔离环境实现并验收；原生语音两项阻塞，第十七步整体未完成，不进入第十八步。**

教师入口：题库、组卷与考试。题库支持手工录题、引用已发布课时原题、通过原ModelJob/Codex CLI生成候选。候选只可显式存入待审核草稿，核对后才有固定题目版本；不自动采用或发布。已有课程题目保留lessonId/versionId/questionId和原来源文字。题干、方程、题型、知识点、难度、分值、答案、解析及来源均保存；适用范围外的数学表达保留待人工核对。

组卷按单元、知识点、题型、难度、题数及总分确定性选择，先覆盖所选知识点再补足题数。缺题给出数量或缺失知识点，不偷偷加入无关题。可手选增删、拖动或键盘按钮调序、修改分值、预览、保存草稿、审核成版本并发布到班级当前学生。后续题目、教案或试卷草稿编辑不修改已发布考试的快照。

学生从“我的考试”开始。未开始前不返回试题；开始后只返回题干与分值等学生字段，不返回答案、解析、评分或未发布成绩。答案与过程显式保存到服务器，切题保留本地编辑，刷新读取已保存草稿。正式提交后只读，同请求重交不修改原答；开始、截止和个人限时由服务器执行。超时写入会用已保存草稿交卷，不采纳客户端超时后的新答案。当前不是后台定时监考系统；未打开/未触发操作的答卷在教师截止后发布成绩时完成空白或保存草稿核验。

程序只核验支持范围内的数值/表达式。应用题数值吻合不会自动给满分；不能核验的题待人工。教师可查看原答、原解释、程序结果，填得分与具体意见，保存前后批阅审计。总分由服务端逐题相加；分数不得超过本题范围。已确认发布的成绩不可改写，学生才能看到参考解答、批阅和讲评。未交卷或未完成必要批阅时拒绝发布。

成绩发布时才把原考试结果投影为现有LearningTask/StudentRecord/Attempt，用于讲评、错题帮与学习记忆，不建第二套账号/模型/画像。错题保留examId、submissionId、paperVersionId、questionVersionId和原始答案；补救产生新记录，不把原始考试答案改对。当前面向普通在线教学考试，不具备远程监考承诺。

方程教具支持两边同加、同减、同乘及同除非零有理数、撤销、重置和解释保存。服务器从原题与动作重算状态，拒绝乘零、除零、变量操作数或任意执行代码，刷新可恢复。前端只渲染受约束JSON。原天平与其VisualizationSpec继续复用。

语音沿用SpeechInput/SpeechReader：识别结果先进入可修改确认窗口，确认仅填入表单，不直接提交问题；朗读分段、暂停、继续、停止，题目ID改变时取消，即使两题文字相同也取消旧任务。3项模拟引擎浏览器回归通过；真实原生API另验：麦克风授权后能打开录音流，但未取得识别文字，系统voices为空，中文播放不能完成。不能把控制逻辑测试算成实机识别或播放通过。

导出复用既有DOCX模板，中文宋体、拉丁和数字Times New Roman、纯黑、A4。支持学生版、教师版、原始答卷、班级成绩、考试学习记录，以及学习记录页的本人完整课程/考试学习记录。教师导出须受班级/学生权限限制，学生不得导出教师版或班级成绩；学生卷没有参考答案及内部规则。
