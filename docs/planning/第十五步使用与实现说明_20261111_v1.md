# 第十五步使用与实现

2026-11-11，v1。

教师从教学概览“班级学情与补充教学”进入，选择班级、任务和日期，查看知识点、题目或学生。点击共性问题可回看原答；点“安排教学”确认学生、实际课时/错题、教师安排和截止日期，先预览再发布。需要教学经验时先从知识点检索案例，阅读后返回用于补充教学。

学生首页收到原有持久消息；进入原任务的“补充与订正”，开始、打开实际内容并提交说明，随后在独立检查或错题帮作答。教师在“教学安排”回看送达、打开、说明与新作答，原任务继续提供逐人反馈。提交说明与独立新题通过分别展示。

学生和教师侧栏“问题与回复”可新建多个问题并查看状态、处理历史；教师可回复或关闭，冲突后输入保留。管理员“反馈与运行”分别处理系统/内容问题、模型异常和账号/运行状态。

既有能力复用：班级/分配/补发/消息、补充安排、LearningMemory、错题帮、BM25案例检索、内容审核版本和ModelJob。新增：统一唯一题目统计，班级/题目/知识/学生投影、干预目标与新作答基线、问题事件队列及失败任务权限核查。

运行：前端npm --prefix frontend run dev，正常入口http://localhost:5177；API8000。升级前备份MySQL，安装已有Python依赖后在backend-business运行python -m sczx_business.commands migrate。技术仍为Vue3/JavaScript、FastAPI/MySQL、既有Codex CLI与LangGraph，不新增React/TypeScript、向量库或队列服务。

本轮采用writing-plans/执行计划、frontend-design/现有Nova方向、design-taste-frontend的真实数据/桌面截图审查、systematic-debugging定位重建和时间问题、verification-before-completion核对交付证据。规则与真实调用、浏览器与受控测试分别记录。

复现命令、夹具、隔离要求、日志及截图见../verification/insights_20261111_v1/README.md。第十五步结束后按已授权规则提交推送，未开发第十六步。
