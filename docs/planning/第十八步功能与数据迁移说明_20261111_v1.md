# 第十八步功能与数据迁移说明

2026-11-11，v1。桌面Web，Vue 3＋JavaScript、Pinia、shadcn-vue/Reka UI、Lucide，FastAPI＋MySQL。沿用账号、班级、课时、任务、题库和学习记忆；没有新增模型服务、消息队列、重复画像或评分体系。

教师导航新增“实时课堂”“分层教学”“教研交流”，学生新增“实时课堂”。本机隔离预发布入口 `http://127.0.0.1:8091`，历史8089/8087保留。本轮新建验收账号均为已有独立演示库的unit-*合成账号，密码仅留本机忽略配置；不是实际师生课堂效果数据。

## 实时课堂

教师选本人班级与已发布课时开始，课堂保存课时和题目快照；推送快照内一道题，学生加入后保存草稿/提交解释，教师看真实加入数、提交数、核验正确/错误/待核对数，公开讲评并结束。页面可见时每3秒轮询，不重叠请求；操作中暂停自动轮询，手动刷新/重试可用；卸载清理定时器，路由generation阻止旧响应覆盖新课堂，同一活动刷新保留未保存输入。

学生仅收到自己的作答；核验及参考答案在教师反馈或课堂结束前不公开。按课堂行加锁，activity＋student唯一；同样重复提交幂等，提交后修改409，新活动不接收旧题回答，结束后不能新增。结束才投影到原LearningTask/StudentRecord/Attempt及错题，保留source=live-class、原始输入、解释和题目来源；仅加入而未提交不会算完成。

## 分层教学

读取原LearningMemory/Attempt/RepairAttempt/考试证据，保存eventId与当时状态快照。建议为补基础、巩固、拓展或证据不足，由教师手调。选择本人已审核试卷版本，版本内题目须关联当前知识点；发布确认后生成原LearningTask＋定向StudentRecord，各组仅收到自己的任务。已发布安排固定，修改需新建安排。

结果来自实际StudentRecord完成与本次任务的独立正确Attempt，不把点击完成/一次受助答对当作掌握，不把短期结果称为真实干预效果。没有新的精确掌握度百分比。

## 教研交流

教师显式确认分享已发布CaseVersion或本人保存的LessonDraftVersion，不自动公开私有草稿。固定快照保留sourceId/versionId；案例未署名明确显示未署名。收藏可取消，讨论与个人使用反馈记录作者和时间，反馈可关联本人实际任务，但仍标为作者自述。本人分享/讨论可撤回并留历史，其他教师不能查看撤回或未发布案例。

改编生成目标课时的独立私有草稿并checkpoint，已有本人草稿返回409保留原稿；不覆盖、不自动发布。保留源分享/版本/作者，后续走既有备课保存、核对、预览、确认班级发布流程。此审核是现有教师核对发布流程，不新增或宣称管理员审批。

HTTP轮询目标是当前规模下约3秒更新；非高并发承诺。数学核验沿用可支持的方程范围，不能核对的保持待核对。课堂内容为既有课时题目活动。工程合成账号与小样本不证明真实教学效果。V01/V03原生语音仍有环境例外，不包含在32项已验收的新功能中。
