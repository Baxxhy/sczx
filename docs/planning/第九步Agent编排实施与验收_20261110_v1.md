# 第九步 Agent 编排实施与验收

日期 2026-11-10　版本 v1

教师有限备课 Agent 已接入现有教学流程。入口为教师备课页“任务备课”。填写课时、任务及约束，生成后可编辑、保存建议、局部重新生成；明确确认后写入当前草稿，教师另行预览和发布。

## 实现

采用 LangGraph 1.2.20 的六节点图：课程上下文 → BM25案例 → 已解析资料 → Codex生成 → 程序校验 → 教师审阅。工具白名单分别为 curriculum.read、retrieval.bm25、materials.read、codex.lesson_plan、plan.validate、teacher.review。参考[官方图接口](https://docs.langchain.com/oss/python/langgraph/graph-api)。

复用现有 ModelJob、ModelRun、事件和SSE。每节点结果写入同一任务的 result，恢复时跳过成功节点；这不是 LangGraph 原生 MySQL checkpointer。服务重启将运行中任务标为失败，手动重试保留成功节点，中断的生成重新调用。最多一次自动重试，整体270秒、生成120秒、数学12秒；工作器300秒外层限制。

服务端读取发布课时、知识和草稿哈希，严格验证块ID及引用ID。最多4案例、6资料片段，不引用尚未解析材料。生成使用现有 Codex CLI gpt-6-luna / low，无新增模型服务。条件方程无法证明时显示“需核对”；目标词重合仅为辅助检查。

确认带草稿哈希及明确 confirmed，跨用户拒绝，重复确认幂等。写入时更新课程来源版本并保留原题目、班情、截止时间；旧任务快照和已发布版本不变。建议保存不会修改正式草稿，Agent不会自动发布。局部生成复用前三节点，只替换指定块，其余编辑保留。前端阻止陈旧自动保存覆盖确认结果。

关键文件：prepare_agent.py、planning_schemas.py、ai_routes.py、model_jobs.py、PlanningAgent.vue、services/planning.js。知识校验、助手竞态与版本精度修复见第八步报告。
