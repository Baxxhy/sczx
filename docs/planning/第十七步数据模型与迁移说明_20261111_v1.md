# 第十七步数据模型与迁移说明

2026-11-11，v1。新增0014_examinations，不删除或改写旧表字段。8个新表：

|表|职责|关联与不变边界|
|---|---|---|
|bank_questions|教师题目ID、可编辑草稿、revision、reviewed|owner_id关联既有accounts，编辑清除当前审核|
|question_versions|审核后的固定题目快照|question_id＋number唯一，追加新版本|
|exam_papers|教师试卷草稿与revision|entries引用真实已审核题目版本|
|paper_versions|固定试卷、题序、分值和题目快照|paper_id＋number唯一，历史不可变|
|class_exams|班级考试、教师、固定卷、时间与成绩状态|既有classrooms、paper_versions；request_key唯一|
|exam_submissions|本人草稿、开始/提交、原始程序结果、当前批阅|exam_id＋student_id唯一，提交后原answers只读|
|exam_grade_audits|批阅前后值、操作人、时间及原revision|追加审计，原automatic与answers不覆盖|
|equation_progress|原学习题的可恢复变形动作和解释|record_id＋question唯一；按revision检查并重放|

ID由服务端生成。题库、试卷、教具和答卷保存均校验版本；批阅采用同一revision控制，并发旧版本409保留页面输入。发布锁既有班级/考试范围，提交按答卷固化状态幂等。MySQL DATETIME为秒级，本步把发布起止时间统一到秒，避免同一请求因微秒丢失误冲突；保留了初验失败证据。
