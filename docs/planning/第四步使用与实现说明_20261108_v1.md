# 第四步使用与实现说明

日期 2026-11-08　版本 v1

## 本步交付

- Vue 3 + JavaScript 前端通过 `/api` 请求独立 FastAPI 业务服务；业务记录写入 MySQL。
- 管理员、教师、学生使用各自账号登录。管理员创建账号；教师创建班级、添加已有学生、编辑教案并发布任务。
- 发布任务保存教案与题目快照。学生的学习解释、进度、求助、作答、错题、补救、提交与教师反馈分别关联到账户和任务。
- 原题图保存为文件资源，任务记录只保存资源路径。管理员可预览旧浏览器数据后导入；历史学生为停用账号，数据留在独立的历史演示班级。
- Alembic 当前迁移为 `0002_file_links_and_supplements`。初始化命令只补充不存在的演示内容，不覆盖已经编辑的记录。

## 本地运行

需要 Python 3.11 或更新版本、Node.js、npm 和可连接的 MySQL。

1. 复制 `backend-business/.env.example` 为 `backend-business/.env`，设置数据库连接、会话配置与管理员/教师/学生初始化密码。此文件已加入忽略规则，不要提交实际密码。
2. 在项目根目录创建并安装 Python 环境：

   ```bash
   python -m venv backend-business/.venv
   backend-business/.venv/bin/pip install -e backend-business
   ```

3. 执行数据库迁移和幂等初始化：

   ```bash
   cd backend-business
   .venv/bin/python -m sczx_business.commands migrate
   .venv/bin/python -m sczx_business.commands seed
   ```

4. 启动业务 API：

   ```bash
   cd backend-business
   .venv/bin/python -m uvicorn sczx_business.main:app --host 127.0.0.1 --port 8000
   ```

5. 在另一终端安装并启动网页端：

   ```bash
   npm --prefix frontend ci
   npm --prefix frontend run dev
   ```

   默认打开 Vite 输出的本地地址（通常为 `http://localhost:5177`）。开发代理将 `/api` 转发到 `127.0.0.1:8000`；需要连接其他 API 地址时设置 `SCZX_API_PROXY`。

6. 首次初始化的账号名由 `.env` 中的 `SCZX_BOOTSTRAP_*_USERNAME` 提供，密码由对应 `SCZX_BOOTSTRAP_*_PASSWORD` 提供。管理员在“反馈与运行”创建额外教师和学生账号。`seed` 不会重置已有账号密码。

API 健康地址为 `/api/health`。题图默认保存到 `backend-business/var/uploads`；可通过 `SCZX_STORAGE_DIR` 指向其他持久目录。

## 首课操作顺序

1. 管理员登录，在“反馈与运行”创建教师和学生账号；旧数据需在此页面预览后明确确认导入。
2. 教师登录，在“班级教学”创建班级并添加学生账号。
3. 在“我的教案”检查活动、目标和截止日期，选择班级并发布。发布时至少需要一名学生。
4. 学生登录，在“我的学习”进入收到的任务，阅读活动、填写解释、请求提示、作答、完成错题补救并提交。
5. 教师打开任务的学情页，选择学生查看作答与求助过程，保存反馈。学生重新登录或刷新页面后可在“本课结果”看到反馈。

## 当前边界

- 当前数学题、提示与补救判定是固定首课示例；不调用模型。更复杂的题目分析和模型 API 在后续步骤接入。
- 浏览器中的会话不是实时推送；跨账号操作后刷新或重新进入页面即可读取最新数据库记录。
- 旧浏览器记录以 `legacy-demo` 来源标记导入。历史学生账号被停用，不会出现在可分配的学生账号列表中。
- 页面用集中 API 服务层读写业务数据。`backend-business/.env` 与 `backend-business/var/` 是运行数据，不提交到 Git。

## 本轮验证记录

- `npm --prefix frontend run build` 通过；Python 业务模块与迁移文件 `compileall` 通过；`git diff --check` 通过。
- 独立 MySQL 实例迁移到 `0002_file_links_and_supplements`；FastAPI `/api/health` 返回数据库可用。
- 独立管理员会话创建教师和学生账号；教师会话建班、加学生并发布任务；学生会话完成解释、求助、两次作答、错题补救和提交；另一教师会话读到记录并保存反馈；学生新会话重新登录后读到反馈。
- 学情页展示 2 次作答、1 次求助、1 次补救和已提交状态；题图上传后通过授权文件地址读回成功；浏览器脚本错误为 0。
- 管理员浏览器显式导入旧 localStorage 样例；导入后仍保留旧浏览器数据，补救关系归入独立历史演示学生；重复导入被识别且不重复创建。
- 本轮浏览器验收使用临时独立数据库和临时浏览器配置，未连接或修改父项目数据库目录。
