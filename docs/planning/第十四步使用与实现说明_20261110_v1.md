# 第十四步使用与实现

2026-11-10，v1。桌面Web，沿用Vue3/JavaScript、Nova、FastAPI/MySQL、原Codex与数学核验；无新增依赖。

学生侧栏增加“学习记忆”，显示知识列表、实际独立作答计数、最近练习、规则状态和可执行建议。点击知识点展开原答、错误/补救、教师反馈、原任务或错题入口、回算的状态变化及修订记录。没有证据时明确显示，不用百分比冒充掌握度。

首页与课时页提供相关复习入口。按建议打开原课时、未作答检查或错题；完成后返回学习记忆，读取新事实后的状态。跨课时复习保留“返回当前课时”入口。稍后处理不会生成教师正式任务，也不改变学习事实。

教师从侧栏或学情详情进入，选择当前班级及学生，核对原证据后可修订知识关联、补观察、标记复核或指定实际复习内容。学生可提出纠正请求；所有决定追加保存，有理由和操作时间。系统规则、模型建议、教师人工意见分别呈现。

刷新自动重算。断网后重新读取；提交修订遇到409时保留输入，先刷新核对当前事实，再确认新决定。加载和切换作用域期间不展示可操作的旧学生数据；迟到响应不覆盖新任务建议或班级列表。无效知识点给出返回入口。

实现入口：learning_memory.py；LearningMemory.vue、MemoryBridge.vue、MemoryReturn.vue；services/memory.js与lib/learning-memory.js。指导上下文只追加有界学习证据，未重做第十二、十三步。原始作答及数学核验仍由已有服务负责。

正常入口http://localhost:5177，API8000。本步隔离验收使用5184/8014，临时账号/连接仅写本机私有文件。数据库迁移与运行方式沿用README。

自动化、实际模型、浏览器和人工预期复核是不同证据。固定14情境只验证规则一致性，不能推断真实课堂成绩或认知状态；当前不开发第十五步完整学情深化。

教师的课程/证据入口打开对应任务学情并保留所选学生，不替学生执行复习；学生入口继续进入学习或补救。
