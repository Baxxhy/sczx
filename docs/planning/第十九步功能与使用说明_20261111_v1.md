# 第十九步功能与使用说明

2026-11-11，v1。沿用Vue3/JavaScript、Pinia、shadcn-vue/Reka、Lucide、Nova灰阶与FastAPI/MySQL，不引入同步服务、模型供应商或新前端依赖。本机独立预发布入口 http://127.0.0.1:8093；正式库仍0013，正式迁移/8000切换未执行。

## 学生使用

1. 在线登录学生账号，从实际侧栏“离线学习”或登录页“打开本机离线学习”进入`/#/offline`。
2. 首次使用设置独立离线口令（至少8位，再次确认）；该口令不是服务器密码。已有下载则填写原账号和离线口令解锁。
3. 选择本人已授权普通任务，点击“下载供离线学习”。图片全部下载并加密写入IndexedDB成功后，才提示已下载。可查看固定版本、下载时间、密文占用和待处理草稿。
4. 断网后使用同一浏览器打开此入口；重启或刷新后重新解锁，读取图文、普通题，保存答案、过程及学习位置。界面只有事务成功才显示已保存到本机。72小时本机离线授权到期后需联网重新下载；旧草稿仍能查看和导出。
5. 联网后先检查学习服务。浏览器关闭后在线会话可能失效，需在线重新登录原账号，再解锁或继续同步。点击“同步草稿”，只同步本人任务的指定题目/位置；同步不是正式作答或交卷。
6. 若服务器有新草稿，展开本机与服务器对照，保留本地副本或确认重新同步。撤回、移出班级、已提交、超时或版本变化不能强行覆盖。
7. “返回在线学习与提交”先重新读取在线身份和最新平台，再进入原学习页；学生按原流程提交作答、服务器核验、提交本课结果。
8. 单项/全部删除均有不可恢复提示。退出默认清除当前账号下载与本机草稿；只有明确勾选“退出时保留加密下载”才保留密文，再次访问仍需原身份和口令。离线退出立即锁定清除，联网后先处理排队的服务器注销。

## 支持边界

可离线：显式下载的图文/例题/普通题阅读、草稿及学习位置保存、查看/导出本机未同步内容。必须联网：课程更新、AI/OCR、课堂、考试、正式提交与评分、教师发布批阅、教研交流、正式成绩。离线页不伪造模型成功、正确答案或正式证据。在线页请求失败保留输入与错误/重试入口；状态以实际API请求为依据，不只看navigator.onLine。

教师撤回普通任务的接口为`POST /api/offline/tasks/{taskId}/withdraw`，校验本人班级并保留任务/原答；本轮用真实教师浏览器请求验证。原学习写入也拒绝已撤回任务。管理端沿用原页面，不新增另一套管理系统。

## 视觉和导航

修复App与实际侧栏各自维护导航导致的入口遗漏，统一到navigation-items.js，显示考试、课堂、分层、社区与离线入口。侧栏可滚动并顶端排列，少量菜单不拉伸成大块。统一长题干/公式换行、图片按比例、键盘焦点、网格最小宽度与离线表单。保持原配色字体，不更换主题，不隐藏原业务按钮。
