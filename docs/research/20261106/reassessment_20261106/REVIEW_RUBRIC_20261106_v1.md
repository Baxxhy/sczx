# 本轮独立评审口径

评审对象是可提交的创新创业/软件创新项目方案，评价其立意、创新、功能、技术、内容与实现论证。正文中的计划按计划评估；已完成成果按所给依据评估。未开发本身不构成方案否决项。

六个分项及权重：动机立意20%、创新设计20%、功能体验15%、技术匹配15%、数据内容15%、线上实现与呈现15%。总体分为加权分，保留一位小数。商业可持续性结合定位、数据供给和实施判断。

分数锚点：90—100为论证突出且具体、关键关系能顺畅落到作品；80—89为方向成熟但有关键表达或设计缺口；70—79为有价值但尚欠完整；60—69为构想较粗。请依据内容自行给分，无目标分和通过线。

每位独立输出六项分数、加权总体、三项优点、至多三项优先修订及对应正文位置；逐条指出可在文档内完成的修复。区分推进论证的必要状态说明与单纯防质疑的文字。外部事实缺口不能靠编造解决。不要读取旧评分、其他评审或其他轮正文。
