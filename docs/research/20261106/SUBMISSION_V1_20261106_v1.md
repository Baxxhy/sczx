# 师承智学：完整项目评审稿

2026-11-06｜V1｜供六角色独立模拟评审。评价方案的清晰、合理、差异化表达与线上可实现性，不把尚未开发作为否决条件。本文描述目标产品和计划；既有能力据产品文档，未新增运行验收。

## 一、作品提出者：我们要做什么

**项目名称：师承智学——优秀教师教学经验驱动的个性化AI学习伙伴。**

**一句话立意：让优秀老师的教法跨越地域，陪学生从听懂一道题走向独立解决一类问题。**

面向K12学生，先做初中数学，重点关注乡村及教育资源相对薄弱地区缺少持续个别指导的学生。以已有错题帮为基础，形成能够理解困难、选择教法、互动辅导、检验掌握并持续陪伴的软件作品。

### 1. 为什么值得做

优秀老师的价值，体现在对教学过程的判断：学生到底卡在哪里，什么时候该举例，什么时候该追问，什么时候该换一种讲法，什么时候可以放手让学生自己做。

项目希望把这些教学判断整理成AI能够使用的经验，让学生在日常学习中获得更适合自己的指导。作品的社会价值落在**优质教学经验的普惠共享，以及学生独立学习能力的培养**。

路演主线：**把优秀教师的教学经验转化为普通学生身边可持续使用的学习支持。**

### 2. 三个相互连接的创新点

**创新一：把优秀教师经验转化为可复用的教学决策。**

从公开教学案例、教研材料和适当授权的教学对话中，整理“学生表现—判断依据—教学目的—适用条件—引导方法—后续调整”。AI辅助提取与归纳，形成带来源的教法案例库。保留一种教法的目标和适用条件后，可以将其用于新的题目情境。

学生感受到的价值：遇到困难时，获得的是针对卡点的一步指导，而不是只收到一篇完整解析。

**创新二：根据学生回应，动态选择和调整教法。**

结合学生当前作答、相关错题和学习过程，在提醒、正确示范、类比搭桥、图示解释、反例对照等方法中选择适合的帮助；学生仍不理解时换法，能够自主继续时减少帮助。相同的表面错误，可以形成不同的教学路径。

学生感受到的价值：伙伴会根据自己的回答改变教法，帮助自己找到能理解的学习方式。

**创新三：用独立作答驱动持续学习。**

把“得到帮助”和“自己会用”连接起来：互动辅导后提供可选择的新题尝试，再结合之后的复习与表现更新下一步学习安排。记录学过什么、用过什么帮助、后来能否独立完成，让下一次学习接得上。

学生感受到的价值：能够看见自己从需要提示到独立完成的进步，伙伴也知道下一次该帮助什么。

三个创新点组成同一条链：

**教师经验进入AI → AI按学生情况选择教法 → 学生的新表现推动后续指导。**

### 3. 六项核心功能

|核心功能|学生将获得什么|与错题帮的关系|
|---|---|---|
|拍题与错题建档|拍照或输入题目，保留原图、原作答和订正过程|复用识别、上传和错题管理|
|学习困难诊断|定位卡住的步骤，区分概念、方法、计算等可能困难|升级错因诊断与证据回放|
|个性化教法选择|根据本次作答与相关历史，选择合适的引导方法|新增教师经验的使用机制|
|互动式学习指导|逐步提示、图示、类比或对照；可主动换讲法|承接已有讲解和数学可视化|
|独立练习与掌握检查|自己尝试新题，了解哪些已经会用、哪些还需帮助|复用练习生成、数学核验和独立作答|
|学习记忆、复习与成长|续接上次任务，复习错题，查看进步和下一步建议|复用记忆、任务规划、复习与报告|

前台收敛为四个入口：**今天、学习、错题、成长**。教师提供经验和内容审阅支持，家长承担必要授权及可选择的成长了解，学生始终是主角。

典型使用过程：带着问题进入 → 确认卡点 → 获得合适的教法 → 自己完成一步 → 可选新题独立尝试 → 之后复习并继续学习。

### 4. 怎样做出有国赛辨识度的展示

演示重点放在“同一道错题，为什么要用不同教法”：能自行修正的学生得到简短提醒；基础概念不清的学生看到正确示范；有相关基础但不会连接的学生获得类比搭桥。随后展示学生独立尝试，以及隔次进入后伙伴怎样接着指导。

让评委在一段连贯演示中看见三件事：**教师经验实际改变了教法，学生的回应实际改变了指导，后续学习实际接续了前次过程。**

### 5. 线上实现路径与难度

**实现难度判断：整体中等偏上，核心演示样机可控；已有错题帮能显著减少从零建设的工作。**

第一步，复用错题帮完成学生端完整学习流程；第二步，围绕初中数学一组课程整理教法案例，接入教法选择和互动调整；第三步，连接独立尝试、复习与成长，再逐步扩展课程覆盖。

首版采用现成大模型和小规模教法材料起步，无需从零训练自己的大模型；开发重点放在教学内容组织、方法选择和学生使用体验。

资料整理、内容编制、软件开发、远程演示和后续在线反馈均可通过电脑完成。可从公开材料与自编中文案例开始，后续通过线上协作补充教师经验，不以实地采集课堂或先取得教育部门合作作为启动条件。

## 二、动机与设计是怎样形成的

这条路线来自三个判断：学生需要的不只是解答，还包括针对卡点的教学过程；优秀教师的经验可以整理为可使用的决策；已有错题帮可以承接学生的长期学习过程。因此将经验供给、教法选择、独立检查连成一个产品，而不是另起一套没有积累的软件。

公开依据与设计贡献分别列明：

|依据|来源和时间|对本项目的作用|
|---|---|---|
|中国学生的过程帮助期待|[中国教科院原始调查](https://www.cnaes.edu.cn/post/151812)，2026-08-26发布，调查发生于2025年8月，321,892份问卷|受访者希望获得提示、漏洞定位与针对练习，支持完整过程帮助方向；这是跨学段自报，不是本项目提分或采用结果|
|专家教学决策可以表达|[Bridge，NAACL 2024](https://aclanthology.org/2024.naacl-long.120/)|参考如何连接学生错误、教学动作与意图。作为研究先例，不把研究数据直接当产品已拥有的名师库|
|代数教法有公开专业依据|[IES/WWC代数教学实践指导](https://ies.ed.gov/ncee/wwc/practiceguide/20)，2015发布、2019修订|参考分析已解问题、关注结构与比较策略；具体学生分支由团队设计，原作者没有明确说的意图不补成原话|
|题目与提示可以组织供给|[OATutor内容仓库](https://github.com/CAHLR/OATutor-Content)，2026-11-06核读说明|题目、提示与脚手架有公开内容先例；选用时逐项保存作者、版本和许可，自编中文材料作为首版默认路径|
|已有软件积累|[错题帮现状说明](../../../../docs/final/IMPLEMENTATION_STATUS.md)，2026-10-22|复用识别、原作答、诊断、练习、独立作答、恢复和复习等产品资产，不重建业务后端|

本项目的创新载体是教学决策内容与连续学生服务：公开原则给依据，团队把适用、禁用、回应和后续学习落实成具体流程。现有研究和AI产品已经具备部分相近能力，作品争取的增量是把这些环节做成学生可持续使用、可解释、可调整的一体体验，不宣称每个组成技术都是首次发明。

## 三、采用什么技术，怎样支撑创新

|技术/方法|承担的任务|学生看到的结果|
|---|---|---|
|多模态大模型＋OCR|识别题干、图示和本人步骤，辅助理解当前疑问|核对原题与原作答，保留原图|
|结构化信息提取|将教学资料整理为来源、目的、先备、动作、适用/禁用、继续/换法/撤助等案例项|教法有可查依据，学生无需填写内部表格|
|语义检索与RAG|找到相关知识和教法候选，再结合本次证据检查适用性|取得针对当前卡点的帮助|
|有限策略规则＋大模型交互|根据先备和回应选择示范、类比、对照或提醒，必要时换法|同题不同教法，能主动纠正AI理解|
|学习证据记忆与任务调度|关联原回答、已用帮助、自主新题与复习结果|隔次继续，避免重复交代；新证据能改旧判断|
|SymPy等数学核验＋Pydantic结构校验|核查可符号化的计算与候选答案、检查输出字段|减少低级错误，数学核验不替代教学判断|
|VisualizationSpec JSON数学图示|将图示交给固定前端组件呈现|获得可交互数学解释，前端不执行模型生成的JavaScript|

技术承载沿用项目主线：uni-app/Vue 3/TypeScript前端，仓颉业务服务与MySQL，Python/FastAPI内部算法。Python只承担算法计算，不读写业务数据库。采用项目现成模型池调用能力，首版不训练自有基础大模型；本文不设计API或数据库。

## 四、数据是什么、从哪里来、怎样形成

|数据类别|来源与取得方式|用途与当前状态|
|---|---|---|
|教学经验依据|公开教研/专业指南；后续可补教师线上提供并授权的原创案例|首版可据公开原则自编，不依赖进校拍摄或预先签约名师；来源有记录|
|教法决策案例|团队根据原则和具体数学目标编制，AI辅助定位、整理和初稿，远程审阅后形成版本|计划新建，当前没有已完成的批量真人审阅库|
|题目、示范、提示和新练习|团队自编中文题目为主；逐项核清可用条件的开放内容为补充|支撑完整学习流程；OATutor等不整库直接搬用，代码许可不替代内容许可|
|学生学习过程|学生实际使用后产生的本人原图、步骤、已看帮助、新回答和复习记录|用于本人的持续指导；当前没有新增真实学生试验数据，也不要求先取得私有学校数据才能做样机|
|演示材料|自编学生情境、预设回答和任务记录|可立即组织作品演示，明确标注构造样例，不当实际提分、用户规模或收入|
|研究参考数据|Bridge及已有知识追踪/教学基准的论文与数据说明|借鉴案例组织与评价思路；不作为首版必须下载或商业复用的数据依赖|

首批生产目标为30条决策案例，按10个初中数学学习目标、每目标2条适用情境和1条不适用情境组织，另配30道独立练习初稿；这些是准备量，不是已完成或已通过数量。先覆盖等式性质与一元一次方程的若干学习目标，完成四入口和跨次体验，再扩展内容，不把30条案例作为产品使命。

生产过程：选择学习目标与来源 → 核对原材料条件 → AI辅助整理 → 作者补适用/禁用和回应分支 → 配示范、新题和可接受解法 → 数学与教学审阅 → 呈现检查 → 保存版本并维护。审阅可以线上完成，原作者未表达的意图保留未知或标团队设计。

一个自编案例说明数据怎样变成行动：原题3x+2=17，学生写3x=19。如果当前能自行修正，就收束帮助；如果明确不理解双边同操作，就先正确示范；如果简单等式能独立处理却不会连接3x这个整体，可以用熟悉子任务搭桥。先看能否自己写出3x=15，系数消元另核；后续可选纯题干新题2y+3=11，作者答案y=4。原题受助完成、新题自主完成及之后复习分开记录。此例是团队构造，不冒充教师原话或真人效果。

## 五、完整学生旅程与首版交付

学生进入“今天”，可以继续未完、复习或主动带题；在“学习”核对原题与卡点，获得适用教法并自己行动；任务的原图、回答与帮助保存在“错题”；新题、复习和下一步建议进入“成长”。学生可结束、暂停、换讲法；已会则减少帮助。当前题没有合格内容就保存待查，额度不足只在匹配的固定帮助存在时转固定，旧域资料不冒充新域指导。

首版交付一款连续可演示的软件样机、一组教法案例和独立练习、同题不同路径的演示，以及跨次继续和成长页面。所有作品呈现都服务一个判断：学生是否能在适合自己的帮助之后，更独立地继续学习。

|阶段|明确产物|难度控制|
|---|---|---|
|内容准备|公开来源清单、30案例/30练习初稿目标、一段连贯自编演示|从少量数学目标开始，优先固定合格内容|
|核心样机|四入口连接已有错题帮，展示选择教法、互动与自主作答|复用现有产品和现成模型，新增重点放教法使用|
|作品完善|跨次继续、复习成长、来源说明与演示材料|在线演示与远程反馈即可开展，不以实地采集为前置|

首批内容依靠公开专业依据和自编材料启动；远程数学/教学审阅是后续内容质量工作，可按材料逐步安排。样机可先使用标明的演示材料展示机制，正式支持清单按实际审阅扩充。整体实现难度中等偏上、核心演示可控；不以新建教师管理平台、硬件或自研基础模型增加工程量。

## 六、六角色独立评审口径

本轮是国赛作品方案评价，不是已上线效果验收。六角色为竞赛立意、教育学习、AI技术、产品体验、数据内容、线上实现与作品呈现。每位分别评以下六角度（每项0—100）：动机立意、创新设计、功能体验、技术匹配、数据来源、线上实现与展示；另给总体分。

通过条件：六位总体分及全部36个分项均不低于95。95表示该角度的方案已清晰、合理、能够组织线上样机；不要求立项前已有商业收入、学习因果试验或全K12覆盖。评分独立，不预设分数；有具体缺口应指出，按反馈实改再提交，旧分不覆盖。六角色是同模型模拟评审，不冒充真人专家。评审原文、轮次与修改记录独立保存，正文提交不附先前自评分。
