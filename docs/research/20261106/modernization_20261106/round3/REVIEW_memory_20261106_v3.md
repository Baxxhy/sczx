## 重点核查及解决证据

1. **帮助分类与独立标签：已解决。** 第五节第2点明确三类步骤证据，透露关键操作或判断的定向提示属于该目标受助，中性流程提醒单列；独立证据须未收到该步内容性提示、答案或示范，并已核验同步。第八节策略比较与成长页、记忆提交共用标签，消除了不同模块各自解释“独立”的缺口。
2. **G2结构解释与步骤事实：已解决。** 第五节更新表中，独立写出2y＝8只写入G1该形式的操作事实，G2保留受助、待结构证据；只有自主说明或等价对应表示才新增G2结构连接证据，并允许学生自己的表达。它没有把一个正确等式直接当成对内部理解方式的证明，也不以复述字母A作为掌握条件。
3. **技能维护与在线/离线一致性：已解决。** 第六节发布清单绑定目标先备、技能、来源审阅、动作分支、工具图示、题目和回放版本；普通修订锁定旧任务，错误停用暂停分支、迁移至已审替代包并重新确认受影响目标。每技能同时产生在线动作规格与离线固定分支、自查卡，共用目标、帮助标签及接受条件；恢复按同一口径归并，旧事件仍保留当时版本。
4. **经验优化、比较与留出冻结：已解决。** 第六节先拒绝数学或状态失败，再匿名比较独立关键步、解释自查与帮助负担，由教学审阅者决定采纳。第八节规定预先确定留出允许动作、撤助与可写证据；据留出失败修订后，该例留痕转回归，新版效果另用未暴露留出报告。模拟与真人分开，少提示本身不代表更好。
5. **预算恢复与性能口径：已解决。** 第五节规定暂停、重试、恢复沿用原过程计数，触顶后的未核验过程保持未完，费用分子包含失败和未完消耗。第八节将本地原步呈现、事件上传与服务端核验更新分开计时，规定缓存、网络、视口、并发与重复测量；加载提示不冒充可执行教学反馈。

## 三项优点

- 长期记忆的依据、帮助程度、适用形式、冲突处理和分目标归属可以逐条检查，能解释为什么更新及为什么暂不更新。
- 教师经验从专业原则一路连到技能与回应分支、数学和教学审阅、版本发布及在线/离线执行，内容资产具备首版可维护性。
- 技术贡献通过同原题多路径、独立新题、跨次记忆修正与断网恢复共同展示，评测与演示围绕产品价值组织，2026研究机制已经落到具体教学动作。

## 待实际取证事项

1. 审阅者对目标归属、内容性提示和自主结构表达的判断一致性；真实手写、自由回应下的识别与判断质量。
2. 首组技能、反例、题目和回放的实际制作与数学/教学审阅记录；真实编审工时及依赖版本维护是否可持续。
3. 停用迁移、缓存切换、重复同步、迟到结果、预算中断等实装回放，确认错误记录不写入独立证据，旧证据不被新版本改写。
4. 固定条件下的成本、缓存大小、响应与恢复性能，以及未暴露留出上的对照和消融结果。
5. 经适当授权后真实学生的即时新题、隔次表现、帮助变化与持续使用。模拟回放可检验流程，不能替代这些学习结果。
