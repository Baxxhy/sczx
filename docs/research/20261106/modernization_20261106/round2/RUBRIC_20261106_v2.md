# 独立作品方案评价

对象：面向创新创业/软件作品竞赛的项目计划书，评价可提交的方案质量；建设计划按计划理解，既有事实按文中依据理解。

六项统一维度与权重：动机立意20%、创新设计20%、功能体验15%、技术匹配15%、数据内容15%、线上实现与呈现15%。各项0—100，整体按同一权重计算，十进制四舍五入一位小数。

90—100：论证突出、关键机制具体且能够落到作品；80—89：方向成熟但有影响价值或执行的缺口；70—79：有价值但欠完整。依据内容自行评分，不读取历史评分，不因轮次增加自动加分。

重点检查：技术是否吸收2025—2026的一手进展且引用准确；新技术怎样改变具体教学动作；相近工作与本项目贡献的关系；模型、工具、记忆及内容生产是否连通；首版资源与已有技术栈是否匹配；乡村普惠与完整K12愿景是否保留；文字是否只为防质疑而没有推进论证。

不要把尚待开发、新学生试验、商业收入本身作为方案否决项；不得通过编造实验与合作补缺口。对本稿能修改的问题请具体指出位置、修改建议和重要性。报告六项整数分、加权总体、3项优点、最多3项优先修订，必要状态与防御文字判断。允许独立核查文中一手链接。不要读取其他评审或旧版材料。
