# 功能位置与重复入口分析

判断同时考虑对象、调用、落库、使用场景、移除成本和历史深链接。按任务书限制只删前端无意义重复，不删仍有依赖的后端或数据。

| 对照 | 对象／调用／数据 | 使用场景与移除成本 | 历史及结论 |
|---|---|---|---|
| AI备课页签／备课工具栏AI按钮 | 同一整课lesson_agent路由、同一课时与任务数据 | 同一上下文重复跳转，删除工具栏按钮无额外成本 | 旧agent路由保留；确认冗余1处，已合并 |
| AI改写此活动／整课AI备课 | 同一任务体系但regenerateBlockId不同；前者仅替换一活动，后者目标及全部活动 | 单活动有明确本地对象，删除会失去作用域 | 两者保留；取消重开仍单活动已真验 |
| 首页任务快捷／左侧业务菜单 | 快捷带task/class，菜单为总览 | 用户继续当前任务与查全列表不同；强并会增加定位步骤 | 保留上下文快捷，主菜单归属统一 |
| 学习结果／记录／记忆 | 当前任务完成与反馈／原始多次作答与帮助／跨任务知识证据 | 不同粒度；合并会把下一步、原答和长期证据堆一起 | 保留互相回到原任务的链接 |
| 错题帮／复习建议／练习 | 原题、原图和补救／知识证据建议／新题作答记录 | 不同对象和阶段；不是同一数据表重复操作 | 保留；学生“错题与复习”分组连接 |
| 教师课程／管理员课程内容 | 已发布固定课时选择／新草稿核对发布与停用 | 权限及写入对象不同，合并会暴露管理编辑 | 保留各角色入口 |
| 教学案例／教研交流 | 已审核来源案例检索／教师分享的固定案例或本人教案版本及讨论 | 来源阅读与经验交流不同；复制共享不自动改源 | 保留；双教师互改编及撤回副本不变已验 |
| 案例收藏／教研收藏 | 按教师收藏案例ID／按教师收藏分享ID | 直接资源与具体分享对象不同 | 均保留；前者本轮补真实存储，后者既有持久能力；不再靠一个全局布尔 |
| 班级学情／学生学习记忆 | 班级统计及教学干预／个人知识证据及修订 | 汇总范围不同，强并损失班级或学生上下文 | 保留互链及班级权限 |
| 手工录题／AI候选 | 前者教师输入、后者真实模型候选；最终都需审核固定题版 | 输入来源不同、审核终点相同，不能把候选当发布题 | 保留同题库内两入口；旧试卷版本保护 |
| 帮助与反馈／管理员问题队列 | 同support体系，但创建/本人回读/权限内处理不同 | 角色任务不同；帮助直接进入队列不受上次账号分类影响 | 保留同页按角色；不是新增第二套问题功能 |
| 模型最近任务／失败任务 | 同ModelJob，但前者查输入结果、后者权限内重试 | 数据恢复与故障处置不同；合并会把失败操作一直暴露 | 保留按需展开失败区；P3近期状态联动滞后明确保留 |

初始5处入口或上下文问题：归档任务进入重答、备课丢课时、管理分类重置、筛选折叠、整课AI重复入口，均已修复并由相应角色或技术边界复测。没有为了缩小菜单数删除实质能力。
