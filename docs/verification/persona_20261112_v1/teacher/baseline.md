## 返修项

### P1 TE-P1-01 学生学习过程打开后立即关闭

两个学生均点击无可见结果

建议位置/修复：保留在班级教学→任务→学生；修复打开学生与监听重置的时序

证据：baseline-feedback.png, actions.json#40-46

### P2 TE-P2-01 更多功能缺乏业务分组且重复题库

课程与课时、题库、分层教学、教研交流、学习记忆、问题与回复同级藏于更多；题库又在组卷页签出现

建议位置/修复：题库归组卷与考试页签；分层、学习记忆归班级教学；教研归教学案例或教研独立分区；课程归备课。保留旧URL但减少一级入口。

证据：baseline-layer-nav.png, baseline-bank.png

### P2 TE-P2-02 教学概览全量任务压低最近提交

九条任务全部铺开，首屏只显示前六条；最近提交被压在任务下方

建议位置/修复：概览保留最近3—4条/待处理，完整任务在班级教学；最近提交置于更高区域。

证据：baseline-overview.png

### P2 TE-P2-03 网页数学字体与正文不协调，题库公式过小

UI同Geist/Noto字体栈；公式另用Cambria Math/STIX/Times serif。题库reading-equation根28px、其span13px，截图公式明显小于正文；学生预览内5=5又大于邻文

建议位置/修复：统一网页文字字族；公式按场景受控字号，避免祖先span规则覆盖公式子节点。DOCX字体要求不属于网页本项。

证据：baseline-bank.png, baseline-preview-fonts.png

### P2 TE-P2-04 学习记忆详情单列留大块空白，关联任务难区分

大卡片右侧大量留空；左侧多个等式性质按钮无日期/任务状态辨识，同名来源反复出现

建议位置/修复：作为班级教学中的学生复习/成长记录；桌面用概览与证据并列，来源任务显示必要时间或来源类型。

证据：baseline-memory-detail.png

### P2 TE-P2-05 考试发布时间要求UTC与其余页面北京时间不一致

发布考试表单写UTC，发布后列表转换为北京时间；学习任务截止时间已经写北京时间

建议位置/修复：面向教师统一北京时间输入与显示，转换交由服务。

证据：baseline-exam-timezone.png, actions.json#72-78

### P2 TE-P2-06 保存失败重复三份提示且toast带对勾

一次注入PUT网络失败后全局横幅、页面错误块、底部toast重复同一长错误；底部失败toast仍显示勾

建议位置/修复：一个紧邻保存操作的失败状态与重试主操作，保留本地内容/导出能力；全局错误避免重复。

证据：baseline-save-failure.png

## 验证及边界

- 六故事覆盖UI入口和已说明的操作范围，不等于所有业务全量回归。
