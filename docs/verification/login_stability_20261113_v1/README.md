# 登录注册切换稳定性

2026-11-13 / v1

原因：不同表单高度配合垂直居中，使切换时整张卡片与页签上下移动；页面出现滚动条时还会左右变化。

改为固定顶部起点，卡片底部随内容变化；登录页独立滚动并预留稳定滚动条空间，短窗口可以滚动查看完整表单。取消页签指示条和错误文字的切换动画，保留Element Plus组件。

验证：1440×1000、1920×1000、1440×768、768×600，分别连续切换注册/登录四次。卡片X/Y与页签Y位置误差小于1px，无横向溢出，页签transitionDuration为0s。字段错误回归同时通过（2项定向检查）；生产构建通过。前端继续5175。
